# Start Here: From Zero to a Complete Program

This foundation assumes **no previous Haskell knowledge**. Work through the pages in order. A later page may use only ideas introduced on an earlier page.

<HighlightCard title="The rule for this unit" description="Do not memorize a complete program as a block of mysterious syntax. Learn what each word and symbol means, then assemble the pieces." variant="primary" />

## The learning path

| Step | Lesson | What becomes possible |
|---:|---|---|
| 1 | Programming and the functional model | Explain input, processing, output, storage, values, pure functions, and effects |
| 2 | GHCi from the beginning | Enter expressions, read results, inspect types, and understand the prompt |
| 3 | Values, names, types, and text | Distinguish values, identifiers, characters, and strings |
| 4 | Printing and terminal output | Use and compare `putStr`, `putStrLn`, `print`, and `show` |
| 5 | A complete saved program | Explain `main`, `IO ()`, `do`, indentation, execution order, and comments |
| 6 | Input, bindings, and processing | Read text, bind a result, transform it, and display the answer |
| 7 | Guided laboratory | Prove each skill without copying blindly |

## How to study each lesson

<StepByStep>
  <Step number={1} title="Read the mental model">Explain the idea in ordinary language before touching the syntax.</Step>
  <Step number={2} title="Read every example aloud">Name the function, input, type, operator, and result.</Step>
  <Step number={3} title="Predict first">Write the expected value, type, or terminal output before running anything.</Step>
  <Step number={4} title="Run and compare">Use GHCi or the Haskell Playground and explain any difference.</Step>
  <Step number={5} title="Retrieve from memory">Complete the ten flashcards and ten-question quiz.</Step>
  <Step number={6} title="Build independently">Finish the guided lab, then compare with the commented solution.</Step>
</StepByStep>
