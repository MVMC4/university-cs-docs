# Welcome to University Docs 🎓

This is a documentation-style website built to organize my university notes, resources, and context. 

It is built with **Next.js** and **Fumadocs**, meaning it supports standard Markdown out of the box. I can write my notes in Obsidian, export them as `.md` or `.mdx`, and drop them right into this project.

## Current Focus: Semester III

- **CSI247**: Data Structures
- **CSI243**: Functional Programming
- **CSI213**: Discrete Structures III
- **MAT221**: Calculus I
- **MGT202**: Management *(Pre-requisite for MGT303)*

> **Note:** This site is designed to be clean, searchable (try `Cmd+K` or `Ctrl+K`), and easy to navigate, just like official documentation.
