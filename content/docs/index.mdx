# Welcome to University Docs 🎓

This is my centralized knowledge base for university courses. What started as a personal system to organize my own study notes and resources has grown into a comprehensive documentation hub that I'm sharing to help peers and anyone else tackling similar subjects.

Built with **Next.js** and **Fumadocs**, this site is designed to be clean, highly searchable, and easy to navigate. All notes are written in Markdown/MDX (often drafted in Obsidian) and compiled here for a seamless reading experience.

##  Current Focus: Semester III

Here are the core subjects currently covered in this repository:

- **CSI247**: Data Structures
- **CSI243**: Functional Programming
- **CSI213**: Discrete Structures III
- **MAT221**: Calculus I
- **MGT202**: Management *(Elective)*

> **💡 Tip:** Need to find something specific? Use the command palette by pressing `Cmd+K` (Mac) or `Ctrl+K` (Windows/Linux) to instantly search across all notes and modules.
