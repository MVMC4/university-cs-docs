## How to use a focus block

1. Choose one concrete task before starting.
2. Work only on that task during the focus phase.
3. Step away during the break instead of opening another study task.
4. Use the longer break after completing the configured cycle.

The navbar control and this workspace share one timer. Moving between pages does not create a second countdown.
