# CSI142: Object-Oriented Programming

CSI142 builds directly on CSI141. The available lecture recaps begin with Java fluency and control-flow consolidation before moving into methods, classes, collections, generics, exceptions, and recursion.

## Learning Outcomes

Students should be able to design, implement, test, and explain small Java programs using reusable object-oriented components.

## Syllabus Map

- Java toolchain, input/output, control flow, and debugging refresh
- Arrays, `ArrayList`, command-line arguments, and validation
- Methods, parameters, return values, pass-by-value, scope, and overloading
- Classes, objects, constructors, fields, encapsulation, and object methods
- Collections and generics for reusable data structures
- Exceptions, recursion, testing, and maintainable program design

The Semester 2 lecture recaps are available in **Resources**.
