# CSI132: Discrete Structures II

CSI132 develops the formal reasoning introduced in CSI131. The Semester 2 lecture packs and tutorials move from proof and function techniques to counting, relations, graphs, and number theory.

## Learning Outcomes

By the end of the course, students should be able to:

1. Use definitions and proof techniques precisely.
2. Work with functions, sequences, sums, relations, and graphs.
3. Apply counting methods to finite problems.
4. Use divisibility, primes, greatest common divisors, and modular reasoning.

## Syllabus Map

- Sets and functions
- Proof methods and mathematical induction
- Sequences and summations
- Counting, permutations, and combinations
- Relations and graphs
- Number theory, primes, and the Euclidean algorithm
