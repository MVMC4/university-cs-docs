# Limits and Continuity

The concept of a limit describes the value that a function approaches as the input approaches some value.

## Formal Definition
$\lim_\{x \to c\} f(x) = L$ means that we can make the values of $f(x)$ arbitrarily close to $L$ by taking $x$ sufficiently close to $c$ (but not equal to $c$).

## Evaluating Limits
1. **Direct Substitution**: If $f(x)$ is continuous at $c$, $\lim_\{x \to c\} f(x) = f(c)$.
2. **Factoring**: Used when direct substitution yields $\frac\{0\}\{0\}$.
3. **Rationalization**: Used for limits involving square roots.

## Continuity
A function $f(x)$ is continuous at $x = c$ if:
1. $f(c)$ is defined.
2. $\lim_\{x \to c\} f(x)$ exists.
3. $\lim_\{x \to c\} f(x) = f(c)$.
