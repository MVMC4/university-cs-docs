# Integration by Substitution

<LessonIntroduction eyebrow="Chapter 02 · Pilot" title="Reverse the chain rule deliberately">

Substitution replaces a composite expression and its differential with one new variable. The algebra is only valid when every part of the integral—including definite bounds—is expressed consistently.

</LessonIntroduction>

<LearningObjectives items={[
  "Recognize an inner function together with its derivative up to a constant",
  "Rewrite an integral completely in one variable",
  "Handle constant mismatches and leftover powers",
  "Convert definite bounds before integration",
  "Verify indefinite and definite results"
]} />
