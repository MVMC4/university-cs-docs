# MGT202: Management

This course introduces the fundamental principles of management and organizational behavior. It provides a framework for understanding how organizations function and how to lead them effectively.

*(Note: This is a pre-requisite for MGT303 in future semesters).*

## The Four Functions of Management
1. **Planning**: Setting goals and deciding how to achieve them.
2. **Organizing**: Arranging tasks, people, and resources.
3. **Leading**: Motivating and directing people.
4. **Controlling**: Monitoring performance and making adjustments.
