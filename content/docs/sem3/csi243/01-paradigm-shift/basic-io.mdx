## 1.5 Basic IO and the Main Function

While pure functions describe computations, interacting with the outside world requires the `IO` monad. Haskell strictly separates pure descriptions of effects from their impure execution.

<HighlightCard
  variant="neutral"
  title="Rule 1.5.1: The Entry Point (`main`)"
  description="Every compiled Haskell program must define a `main` function with the specific type signature `IO ()`."
>

```haskell
main :: IO ()
main = putStrLn "Hello, World!"
```

The type `IO ()` represents an I/O action that performs side effects and returns a tuple of type `()` (unit), which carries no information.

</HighlightCard>

<Card>

### Definition 1.5.1 (The `do` Block)

The `do` notation provides syntactic sugar for sequencing I/O actions. It allows imperative-style code while maintaining the underlying monadic purity.

```haskell
main :: IO ()
main = do
    putStrLn "What is your name?"
    name <- getLine
    putStrLn ("Hello, " ++ name)
```

</Card>

<HighlightCard
  variant="neutral"
  title="Rule 1.5.2: The Output Family"
  description="Functions for writing strings and values to the standard output."
>

- `putChar :: Char -> IO ()`: Outputs a single character.
- `putStr :: String -> IO ()`: Outputs a string without a trailing newline.
- `putStrLn :: String -> IO ()`: Outputs a string followed by a newline.
- `print :: Show a => a -> IO ()`: Outputs any value that is an instance of the `Show` typeclass. *Note: `print` adds quotes around Strings, unlike `putStrLn`.*

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Rule 1.5.3: Input and the Bind Operator (`<-`)"
  description="Extracting pure values from impure I/O actions."
>

The `<-` operator is used inside a `do` block to extract the underlying value from an I/O action.

```haskell
getLine :: IO String
```
Using `name <- getLine` extracts the `String` from the `IO String` action, binding it to the pure variable `name`.

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Rule 1.5.4: Type Conversion (`read` and `show`)"
  description="Converting between Strings and primitive types in Haskell."
>

- **`show`**: Converts a value to a `String`. (e.g., `show 5` yields `"5"`).
- **`read`**: Parses a `String` into a specific type. **Mandatory Type Annotation:** Because `read` is polymorphic, the compiler must know the target type.
  ```haskell
  let x = read "5" :: Int
  ```

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Example: A Complete Interactive IO Program</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Define the Program Logic</StepTitle>

    We will prompt the user for their age, read it as an integer, and print it back.
  </Step>

  <Step number={2}>
    <StepTitle>Write the Haskell Code</StepTitle>

    ```haskell
    main :: IO ()
    main = do
        putStr "Enter your age: "
        input <- getLine
        let age = read input :: Int
        putStrLn ("Next year, you will be " ++ show (age + 1))
    ```
  </Step>

  <Step number={3}>
    <StepTitle>Execution Flow</StepTitle>

    1. `putStr` outputs the prompt.
    2. `getLine` captures the user's input as an `IO String`.
    3. `<-` extracts the `String` into `input`.
    4. `read input :: Int` parses the string into an `Int`.
    5. `show (age + 1)` converts the calculated integer back to a `String` for `putStrLn`.
  </Step>
</StepByStep>
