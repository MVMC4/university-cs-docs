## 1.4 The Haskell Toolchain and Compilation

The Haskell ecosystem relies on the Glasgow Haskell Compiler (GHC) and its interactive environment (GHCi). Understanding the toolchain and the strict syntactic rules of Haskell is mandatory for writing valid code.

<HighlightCard
  variant="neutral"
  title="Rule 1.4.1: The Layout Rule (Whitespace as Syntax)"
  description="Haskell uses indentation to define code blocks, strictly prohibiting the mixing of tabs and spaces."
>

- **The Offside Rule:** Code blocks (e.g., inside `let`, `where`, `do`, or `of`) are grouped by indentation.
- **Strict Prohibition:** You must **never** mix tabs and spaces in a Haskell file. The compiler will throw a parse error. Standard practice is to use spaces exclusively.

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Rule 1.4.2: Case Sensitivity"
  description="Haskell uses case to distinguish between values and types/constructors."
>

- **Lowercase:** Used for functions, variables, and parameters (e.g., `myFunc`, `x`, `map`).
- **Uppercase:** Used for Types, Typeclasses, and Data Constructors (e.g., `Int`, `Bool`, `True`, `Just`).

</HighlightCard>

<Card>

### Definition 1.4.1 (Comments in Haskell)

- **Single-line:** Starts with `--` and continues to the end of the line.
- **Multi-line:** Enclosed in `{-` and `-}`. These can be nested.

</Card>

<HighlightCard
  variant="neutral"
  title="Rule 1.4.3: GHCi (The Interactive Interpreter)"
  description="The Read-Eval-Print Loop (REPL) used for testing expressions and loading modules."
>

**Essential Commands:**
- `:load` (`:l`) `filename.hs`: Loads a Haskell script into the REPL.
- `:reload` (`:r`): Reloads the currently loaded modules after changes.
- `:type` (`:t`) `expression`: Prints the type of an expression without evaluating it.
- `:quit` (`:q`): Exits the GHCi session.

**Multi-line Input:** Use `:{` to start and `:}` to end a multi-line definition block in the REPL.

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Rule 1.4.4: GHC (The Batch Compiler)"
  description="Compiling Haskell source code into native machine-code executables."
>

**Compilation Command:**
```bash
ghc -o myProgram myFile.hs
```

**Generated Files:**
- `myProgram`: The native machine-code executable (e.g., `.exe` on Windows).
- `myFile.hi`: The Haskell interface file (contains type information for other modules).
- `myFile.o`: The object file (compiled machine code).

</HighlightCard>

<Card>

### Definition 1.4.2 (runhaskell)

The `runhaskell` command interprets a script directly and executes it without generating `.o` or `.hi` object files. It is useful for quick scripting but slower for repeated execution.

</Card>
