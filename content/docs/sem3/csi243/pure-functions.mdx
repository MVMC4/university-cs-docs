# Pure Functions

A pure function is a function that, given the same input, will always return the same output and has **no side effects**.

## Characteristics
1. **Deterministic**: $f(x)$ always equals $y$ for the same $x$.
2. **No Side Effects**: It does not modify external state, log to the console, or make network requests.

## Example: Impure vs Pure

```javascript
// Impure: Modifies external state and relies on it
let multiplier = 2;
function multiplyImpure(arr) {
  return arr.map(x => x * multiplier);
}

// Pure: Takes all dependencies as arguments, returns new data
function multiplyPure(arr, multiplier) {
  return arr.map(x => x * multiplier);
}
```
