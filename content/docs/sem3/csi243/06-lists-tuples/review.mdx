## Decoding the questions

Lab and exam questions describe a function in wording that is precise but far denser than the function itself. The gap between "I do not understand this question" and "I do not understand Haskell" is often just that: the English needs decoding before the Haskell can start. Open the reference below, then work through the questions from this chapter.

<DecodeQuestion course="csi243" title={"\"Together with ... as a pair\""} source="CSI243 lab" question={"Define a function `atPosition` that takes a list and a number `y` and returns the element at position `y`, together with `y` as a pair (2-tuple)."} plain={"Return two things at once: the element, and the position you were asked for. Bundle them in a tuple."}>

"Together with ... as a pair" is this course's dictionary entry for **"the return type is a tuple, and here is what goes in each slot."** The order matters and is stated explicitly here — `atPosition [3,5,2,10] 3` must return `(3,10)`, i.e. `(y, element)`, position first.

```haskell
atPosition :: [a] -> Int -> (Int, a)
atPosition xs y
  | y < 0 || y >= length xs = error "atPosition: index out of range"
  | otherwise                = (y, xs !! y)
```
```haskell
main :: IO ()
main = print (atPosition [3, 5, 2, 10] 3)
```
```text
(3,10)
```

</DecodeQuestion>
