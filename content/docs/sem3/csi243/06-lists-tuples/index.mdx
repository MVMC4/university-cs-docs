## Chapter 6: Lists, Tuples, and Comprehensions

Chapters 4 and 5 gave you choice and repetition. This chapter gives you the data to apply them to. Almost every remaining problem in CSI243 is a question about a collection.

Two structures cover most needs, and they differ in exactly two ways:

| | List | Tuple |
|---|---|---|
| Length | May vary at run time | Fixed by its type |
| Element types | All the same | Each position may differ |

## The one idea to carry forward

Every list is either empty, or an element consed onto another list:

```haskell
functionName []     = -- the answer for an empty list
functionName (x:xs) = -- combine x with functionName xs
```

That pair of patterns is exhaustive, and the tail is always shorter than the list you started with. Together those two facts make every list function in this chapter both total and terminating.

## Chapter outcomes

- Build lists with literals, ranges, and cons, and explain why lists are homogeneous.
- Use the Prelude list operations and identify which of them are partial.
- Define `length`, `sum`, `product`, and `null` recursively from scratch.
- Write recursive functions that transform, filter, and inspect lists.
- Group values with tuples, destructure them with patterns, and return several results.
- Choose correctly between a list and a tuple for a given problem.
- Read and write list comprehensions with generators, tests, and multiple generators.
- Translate between a comprehension and the equivalent recursion.
