# Chapter 5: Algebraic Data Types & The Module System

This chapter explores how to model complex domain data using Algebraic Data Types (ADTs) and how to organize and encapsulate that code using Haskell's Module System. We will cover type synonyms, sum and product types, recursive data structures, and the enforcement of invariants via smart constructors.
