# Application Development & Architecture

To transition from theoretical exercises to real-world software, you must master Haskell's tooling and apply functional patterns to solve architectural problems.

## Tooling: Stack & Cabal
- **Cabal**: The standard package format and build system for Haskell.
- **Stack**: A cross-platform build tool that manages GHC versions, dependencies, and reproducible builds. 
> **Rule**: Always initialize new projects with `stack new my-project` to ensure a clean, isolated environment.

## Lab 3: Proving Functor Laws
Define a custom binary tree: `data Tree a = Empty | Node a (Tree a) (Tree a)`.
Write the `Functor` instance and mathematically prove (using structural induction) that it satisfies:
1. **Identity Law**: `fmap id = id`
2. **Composition Law**: `fmap (f . g) = fmap f . fmap g`

*Proof of Identity Law for Tree (Base Case):*
```haskell
fmap id Empty 
= Empty                  -- Definition of fmap for Empty
= id Empty               -- Definition of id
```
*The base case holds. The inductive step follows similarly for `Node`.*

## Building Real Applications
