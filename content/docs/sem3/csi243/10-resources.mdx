# Course Resources

## Required Textbooks
1. **Haskell: The Craft of Functional Programming (3rd Ed)** - Simon Thompson
2. **Learn You a Haskell for Great Good!** - Miran Lipovaca

## Supplementary Reading
3. **Models of Computation** - M. Fernandez
4. **A Mathematical Introduction to Logic** - H.B. Enderton

## Essential Tools
- **GHCup**: The recommended installer for GHC, Cabal, Stack, and Haskell Language Server (HLS).
- **Hoogle**: The ultimate Haskell API search engine (search by type signature!).
- **UB Moodle Portal**: http://www.cs.ub.bw/moodle/

> **Tip**: When stuck, try searching the type signature of the function you need in Hoogle. It is often the fastest way to find the right standard library function.
