## Chapter 2: Haskell Basics

These lessons take you from an empty machine to a running Haskell program, then establish the language vocabulary required before functions and input/output.

| Order | Lesson | Main question |
|---:|---|---|
| 1 | [Setting Up and Using GHCi](/docs/sem3/csi243/02-expressions-types/notes/ghci) | How do I install Haskell, enter an expression, inspect its type, and read the result? |
| 2 | [Your First Haskell Program](/docs/sem3/csi243/02-expressions-types/notes/first-program) | How do I save work in a file, load it, run it, and compile it? |
| 3 | [Values, Names, Types, and Text](/docs/sem3/csi243/02-expressions-types/notes/values-text) | How does Haskell distinguish data from program names? |
| 4 | [Expressions and Types](/docs/sem3/csi243/02-expressions-types/notes/expressions-types) | How do types determine whether an expression is meaningful? |

After the notes, use [Practice Questions](/docs/sem3/csi243/02-expressions-types/questions) and then [Review](/docs/sem3/csi243/02-expressions-types/review).

## Chapter outcomes

- Install the Haskell toolchain and prove that GHC and GHCi work.
- Distinguish the GHCi prompt, entered expressions, and displayed results.
- Write a `.hs` script, load it, run `main`, and reload it after an edit.
- Compile a script into a standalone executable and explain the files produced.
- Read `::` as “has type.”
- Distinguish identifiers, literals, `Char`, and `String`.
- Predict the grouping and result of small expressions.
- Diagnose basic syntax and type errors.
