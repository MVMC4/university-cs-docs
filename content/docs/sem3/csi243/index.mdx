## CSI243 Functional Programming

This course develops Haskell in dependency order: first the programming model, then the language basics, then functions and input/output. Later chapters extend the same foundation into choices, recursion, collections, higher-order functions, modules, and custom types.

## Course outcomes

By the end of the completed course, students should be able to:

- explain functional programming and compare it with imperative programming;
- read and write typed Haskell expressions and functions;
- separate pure transformations from input/output actions;
- solve problems with pattern matching, recursion, collections, and higher-order functions;
- organize programs with modules and custom data types;
- interpret compiler feedback and test programs systematically;
- reason about program behavior and basic complexity.
