# CSI243: Functional Programming - Course Index & Roadmap

## Course Information
- **Credits:** 3
- **Pre-requisites:** CSI142
- **Co-requisites:** None

## Aims and Learning Objectives
The course aims to introduce Functional Programming as one of the models in Computer Science. It introduces the main concepts behind the functional programming paradigm and problem solving using functional languages. It emphasizes important concepts such as recursive definitions, higher-order functions, and type inference. Programming exercises illustrate the utility of list-processing, pattern matching, abstraction of data/control, strong typing, and parameterized modules (functors). This course also emphasizes mathematical reasoning involved in the design of functional programs and techniques for proving properties about functions so defined.

## Learning Outcomes
Upon successful completion of the course, students should be able to:
1. Explain the principles and techniques of programming with functions.
2. Explain the main features of a modern functional language.
3. Write non-trivial functional programs.
4. Develop applications using functional programming languages.

## Documentation Index & Syllabus Mapping
This index maps the official course topics to the specific chapters in the documentation.

### 01. Paradigm Shift
- **Syllabus Topic:** Define functional programming, and compare to imperative programming languages.
- **Documentation Focus:** Introduction to the FP mindset, immutability, pure functions, and the shift from imperative to declarative programming.

### 02. Haskell Basics, GHCi & Basic IO
- **Syllabus Topic:** Design, implement, and test applications using Haskell.
- **Documentation Focus:** Navigating GHCi, the Layout Rule, case sensitivity, if-then-else expressions, read/show with type annotations, and basic do-block IO.

### 03. Syntax, Pattern Matching & Choices
- **Syllabus Topic:** List-processing, pattern matching, definitions of functions, abstraction of data/control.
- **Documentation Focus:** Tuples, mechanical pattern matching, Guards, case expressions, local bindings (let...in vs where), currying, closures, and point-free style.

### 04. ADTs & Modules
- **Syllabus Topic:** Abstract data types, strong typing, and parameterized modules.
- **Documentation Focus:** Defining custom data types, type synonyms, recursive data types, and organizing code using Haskell's module system.

### 05. Polymorphism & Typeclasses
- **Syllabus Topic:** Define polymorphism, abstract data types, type checking, and type inference.
- **Documentation Focus:** Parametric polymorphism, ad-hoc polymorphism (overloading), defining custom Typeclasses, standard hierarchies (Eq, Ord, Num, Show, Read), and Hindley-Milner unification.

### 06. Recursion, Lists & Induction
- **Syllabus Topic:** Recursive definitions, mathematical reasoning in the design of functional programs, overview of complexity of functions.
- **Documentation Focus:** Anatomy of recursion, dry-running mechanics, structural induction proofs, and time/space complexity analysis of recursive functions.

### 07. Higher-Order Functions & List Processing
- **Syllabus Topic:** Higher-order functions, list-processing.
- **Documentation Focus:** map, filter, foldr, foldl', list comprehensions, standard library functions, and GHC rewrite rules.

### 08. Abstractions (Advanced/Bonus)
- **Syllabus Topic:** Abstraction of data/control, parameterized modules (functors).
- **Documentation Focus:** Functor laws, Applicative error accumulation, Monad laws, Kleisli composition, and do-notation desugaring. (Note: Considered bonus material not explicitly tested in standard labs).

### 09. IO & The Monad (Advanced/Bonus)
- **Syllabus Topic:** Develop applications using functional programming languages.
- **Documentation Focus:** The Recipe pattern (IO as an AST), the State# RealWorld token, IORef for controlled mutable state, and exception handling. (Note: Considered bonus material not explicitly tested in standard labs).
