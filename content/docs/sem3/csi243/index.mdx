# CSI243: Functional Programming

Functional Programming (FP) is a programming paradigm that treats computation as the evaluation of mathematical functions and avoids changing-state and mutable data.

## Key Paradigms
- **Declarative over Imperative**: Focus on *what* to solve, not *how* to solve it.
- **First-Class Functions**: Functions can be assigned to variables, passed as arguments, and returned from other functions.
- **Immutability**: Data cannot be changed after creation; new data structures are returned instead.
