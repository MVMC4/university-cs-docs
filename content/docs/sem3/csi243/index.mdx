# CSI243: Functional Programming

Welcome to **CSI243**. This course bridges the gap between mathematical logic and modern software architecture, teaching you to think in terms of pure functions, immutable data, and rigorous proofs.

## 📅 Schedule
- **Lecture**: Tuesday 12:00 – 14:00 (Block 247, Room 035)
- **Lab**: Thursday 11:00 – 13:00 (Block 247, Labs 292/293)
- **Lecturer**: Tebogo Seipone (seiponet@ub.ac.bw)

## 🎯 Core Learning Outcomes
By the end of this course, you will be able to:
1. Master the Lambda Calculus and the concept of Pure Functions.
2. Implement complex logic elegantly via Recursion and Higher-Order Functions.
3. Prove program correctness using Structural Induction and Equational Reasoning.
4. Build real-world, side-effecting applications using the IO Monad and modern tooling.
