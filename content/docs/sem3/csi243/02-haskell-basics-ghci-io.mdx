# Chapter 2: Haskell Basics, GHCi & Basic IO

## Learning Objectives
1. Navigate GHCi using essential commands (`:load`, `:type`, `:quit`, `:{ ... :}`).
2. Apply Haskell's layout rule (indentation) and understand case sensitivity.
3. Use `if-then-else` expressions, emphasizing the mandatory `else` branch.
4. Convert between strings and values using `read` and `show` with type annotations.
5. Construct basic `do` blocks for IO using `getLine`, `<-`, `putStrLn`, and `print`.
6. Differentiate between `putStr`, `putStrLn`, `putChar`, and `print`, and understand how to compile Haskell scripts.

## 2.1 Case Sensitivity & The Layout Rule

Haskell is strictly case-sensitive and uses whitespace to define scope (the **Layout Rule**).
- **Case Sensitivity**: Variables and functions **must** start with a lowercase letter (e.g., `myFunc`, `x`). Types and Data Constructors **must** start with an uppercase letter (e.g., `Int`, `Just`, `True`).
- **Layout Rule**: Code blocks introduced by keywords like `where`, `let`, `do`, or `case` must be indented *further* than the keyword itself. Mixing tabs and spaces is discouraged; stick to spaces (typically 2 or 4).

## 2.2 Essential GHCi Commands

GHCi is Haskell's interactive REPL (Read-Eval-Print Loop).
- `:load` (or `:l`) `filename.hs` — Loads a Haskell source file.
- `:type` (or `:t`) `expression` — Shows the type of an expression.
- `:quit` (or `:q`) — Exits GHCi.
- `:{` and `:}` — Allows multi-line input directly in the GHCi prompt.

```haskell
ghci> :{
ghci| add :: Int -> Int -> Int
ghci| add x y = x + y
ghci| :}
ghci> :t add
add :: Int -> Int -> Int
```

## 2.3 `if-then-else` Expressions

In Haskell, `if` is an **expression**, not a statement. This means it must evaluate to a value in all possible execution paths. Therefore, the `else` branch is **mandatory**.

```haskell
-- CORRECT: 'else' is mandatory
absoluteValue :: Int -> Int
absoluteValue x = if x < 0 then -x else x

-- WRONG: Missing 'else' branch (Compiler Error!)
-- badAbsoluteValue x = if x < 0 then -x
```

## 2.4 `read` and `show` with Type Annotations

- `show` converts a value into its `String` representation.
- `read` parses a `String` into a value. Because `read` is polymorphic, you often must provide a **type annotation** so the compiler knows what type to parse it as.

```haskell
ghci> show 42
"42"
ghci> read "5" :: Int
5
ghci> read "3.14" :: Double
3.14
-- Without the type annotation, GHCi may throw an "Ambiguous type variable" error.
```

## 2.5 Basic IO: `do` blocks, `getLine`, `<-`, `putStrLn`, `print`

IO actions in Haskell are sequenced using `do` blocks. The `<-` operator is used to extract the pure value from an IO action.
- `putStrLn :: String -> IO ()` prints a string followed by a newline.
- `print :: Show a => a -> IO ()` prints any value that is an instance of the `Show` typeclass.
- `getLine :: IO String` reads a line of input from the user.

### Hello World Script
```haskell
main :: IO ()
main = do
    putStrLn "Hello, World!"
```

### Triangle Area Script (Lecture 3)
```haskell
main :: IO ()
main = do
    putStrLn "Enter the base of the triangle:"
    baseStr <- getLine
    putStrLn "Enter the height of the triangle:"
    heightStr <- getLine
    
    -- Use 'let' to bind pure values inside a 'do' block
    let base = read baseStr :: Double
        height = read heightStr :: Double
        area = 0.5 * base * height
        
    putStrLn "The area of the triangle is:"
    print area
```

## 2.6 Comments, Output Functions & Compilation

### Comments
Haskell supports single-line and nested multi-line comments.
```haskell
-- This is a single-line comment

{- This is a multi-line comment.
   It can span several lines and even {- nest -} other comments. -}
```

### The Output Family (`putStr` vs `putStrLn` vs `putChar` vs `print`)
Lecture 3 explicitly tests your knowledge of how these differ:
- `putChar :: Char -> IO ()` prints a single character.
- `putStr :: String -> IO ()` prints a string **without** a newline.
- `putStrLn :: String -> IO ()` prints a string **with** a trailing newline.
- `print :: Show a => a -> IO ()` converts any showable type to a string (using `show`) and prints it with a newline. Strings printed via `print` will include the quotation marks (e.g., `print "Hello"` outputs `"Hello"`).

### Compilation vs Interpretation
While GHCi interprets code interactively, you can compile scripts to standalone executables using the terminal:

```bash
# Compile to an executable named 'hello'
ghc -o hello hello.hs

# Run the executable
./hello

# Or interpret a script directly without compiling to an object file
runhaskell custom.hs
```
