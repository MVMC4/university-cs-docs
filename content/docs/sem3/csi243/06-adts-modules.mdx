# Algebraic Data Types (ADTs) & Modules

Algebraic Data Types (ADTs) are the cornerstone of domain modeling in Haskell. They allow you to define custom data structures with mathematical precision. The term "Algebraic" comes from the fact that types can be combined using sums (OR) and products (AND).

## Product Types (AND)
A product type combines multiple values into a single type. A `Tuple` or a standard `data` declaration with a single constructor is a product type because the number of possible values is the *product* of the possibilities of its fields.

```haskell
-- Standard Product Type
data Point = Point Float Float

-- Record Syntax (Recommended)
-- Automatically generates getter functions: `pointX` and `pointY`
data PointRecord = PointRecord { pointX :: Float, pointY :: Float }
```
> **Analogy**: Think of a product type like a struct in C or a class in Java. It's an "AND" relationship: a `Point` has an X coordinate **AND** a Y coordinate.

## Sum Types (OR)
A sum type represents a choice between multiple alternatives. The number of possible values is the *sum* of the possibilities of each constructor.

```haskell
data Shape = Circle Float | Rectangle Float Float | Triangle Float Float Float
```
> **Analogy**: Think of a sum type like an `enum` in Java or C, but vastly more powerful because each alternative can carry its own distinct data payload.

## Recursive ADTs
ADTs can refer to themselves, enabling the creation of hierarchical, tree-like structures.

```haskell
data List a = Empty | Cons a (List a)
data Tree a = EmptyTree | Node a (Tree a) (Tree a)
```

## Modules & Information Hiding
Haskell uses modules to organize code and enforce encapsulation. By carefully crafting the `module ... where` export list, you can hide the internal representation of an ADT, forcing users to interact with it only through provided API functions.

```haskell
module Stack (Stack, empty, push, pop) where

-- The internal list is hidden from the user!
-- They cannot pattern match on `Stack` directly.
newtype Stack a = Stack [a]

empty :: Stack a
empty = Stack []

push :: a -> Stack a -> Stack a
push x (Stack xs) = Stack (x : xs)
```
This guarantees **invariants** (e.g., a stack can never be manually constructed in an invalid state).
