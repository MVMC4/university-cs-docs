# Logic and Proofs

Mathematical proofs are the backbone of computer science, ensuring that algorithms and systems behave exactly as intended.

## Propositional Logic
Statements that are either True (T) or False (F).
- **Conjunction ($\land$)**: AND
- **Disjunction ($\lor$)**: OR
- **Negation ($\neg$)**: NOT
- **Implication ($\rightarrow$)**: If P, then Q.

## Methods of Proof
1. **Direct Proof**: Assume P is true, logically deduce Q.
2. **Proof by Contrapositive**: Prove $\neg Q \rightarrow \neg P$ instead of $P \rightarrow Q$.
3. **Proof by Contradiction**: Assume the statement is false, and show this leads to a logical impossibility.
4. **Mathematical Induction**: Prove a base case, then prove that if it holds for $k$, it holds for $k+1$.
