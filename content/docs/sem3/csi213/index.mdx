# CSI213: Discrete Structures III

This course builds on foundational mathematics, focusing on formal logic, rigorous proof techniques, and the mathematical structures that underpin computer science.

## Core Topics
- Propositional and Predicate Logic
- Methods of Proof (Direct, Contrapositive, Contradiction, Induction)
- Relations and Functions
- Graph Theory (Paths, Cycles, Trees, Planar Graphs)
