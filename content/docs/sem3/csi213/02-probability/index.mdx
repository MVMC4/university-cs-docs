### [2.1 Axiomatic Probability Theory](/docs/probability/axioms)
The foundational rules governing any probability space and their direct mathematical consequences.

* **The Kolmogorov Axioms:** Explicitly stating Axiom I (Non-negativity), Axiom II (Normalization), and Axiom III (Countable Additivity).
* **Theorem 2.1.3 (Addition Rule):** Proving $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ by partitioning $A \cup B = (A \cap B^c) \cup B$ and applying Axiom III.
* **Theorem 2.1.4 (Monotonicity):** Proving that if $A \subset B$, then $P(A) \le P(B)$ using the partition $B = A \cup (B \cap A^c)$.
