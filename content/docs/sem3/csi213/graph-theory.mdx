# Graph Theory

A graph $G = (V, E)$ consists of a set of vertices (nodes) $V$ and a set of edges $E$ connecting pairs of vertices.

## Key Concepts
- **Degree**: The number of edges connected to a vertex.
- **Path**: A sequence of edges connecting a sequence of distinct vertices.
- **Cycle**: A path that starts and ends at the same vertex.
- **Connected Graph**: There is a path between every pair of vertices.

## Handshaking Lemma
The sum of the degrees of all vertices in an undirected graph is equal to twice the number of edges:
$$ \sum_\{v \in V\} deg(v) = 2|E| $$
