# Welcome to Semester III

This semester marks a deep dive into core computer science theory, advanced mathematics, and foundational management principles. 

## Core Courses (15 Credits)
- **CSI247**: Data Structures
- **CSI243**: Functional Programming
- **CSI213**: Discrete Structures III
- **MAT221**: Calculus I

## Elective (3 Credits)
- **MGT202**: Management *(Note: This is a pre-requisite for MGT303 in future semesters).*
