## 4.4 Queue ADT, Circular Arrays & BFS

The Queue is a restricted linear structure that enforces a strict First-In, First-Out (FIFO) access pattern.

<HighlightCard
  variant="neutral"
  title="Complete Java Implementation: CircularQueue"
  description="Array-based circular queue with modulo arithmetic and 1-slot sacrifice."
>

```java
import java.util.NoSuchElementException;

public class CircularQueue<T> {
    private final Object[] elements;
    private int front;  // Index of front element
    private int rear;   // Index where next element will be inserted
    private int size;
    private final int capacity;

    public CircularQueue(int capacity) {
        // Allocate capacity + 1 to distinguish full from empty
        this.capacity = capacity + 1;
        this.elements = new Object[this.capacity];
        this.front = 0;
        this.rear = 0;
        this.size = 0;
    }

    public void enqueue(T item) {
        if (isFull()) {
            throw new IllegalStateException("Queue is full");
        }

        elements[rear] = item;
        rear = (rear + 1) % capacity;  // Wrap around using modulo
        size++;
    }

    @SuppressWarnings("unchecked")
    public T dequeue() {
        if (isEmpty()) {
            throw new NoSuchElementException("Queue is empty");
        }

        T item = (T) elements[front];
        elements[front] = null;  // Prevent memory leak
        front = (front + 1) % capacity;  // Wrap around
        size--;
        return item;
    }

    @SuppressWarnings("unchecked")
    public T peek() {
        if (isEmpty()) {
            throw new NoSuchElementException("Queue is empty");
        }
        return (T) elements[front];
    }

    public boolean isEmpty() {
        return size == 0;
    }

    public boolean isFull() {
        // Full when rear would wrap around to front
        return (rear + 1) % capacity == front;
    }

    public int size() {
        return size;
    }
}
```

**Key Features:**
1. **Modulo arithmetic**: `(index + 1) % capacity` wraps the pointer back to 0
2. **1-slot sacrifice**: We allocate `capacity + 1` slots to distinguish full from empty
3. **Memory leak prevention**: Setting `elements[front] = null` after dequeue

<HighlightCard
  variant="neutral"
  title="Application: Breadth-First Search (BFS)"
  description="Using CircularQueue for graph traversal."
>

```java
public class Graph {
    private final List<List<Integer>> adjList;
    private final int V;  // Number of vertices

    public Graph(int V) {
        this.V = V;
        adjList = new ArrayList<>();
        for (int i = 0; i < V; i++) {
            adjList.add(new ArrayList<>());
        }
    }

    public void addEdge(int u, int v) {
        adjList.get(u).add(v);
        adjList.get(v).add(u);  // Undirected graph
    }

    public List<Integer> bfs(int start) {
        boolean[] visited = new boolean[V];
        CircularQueue<Integer> queue = new CircularQueue<>(V);
        List<Integer> result = new ArrayList<>();

        visited[start] = true;
        queue.enqueue(start);

        while (!queue.isEmpty()) {
            int u = queue.dequeue();
            result.add(u);

            for (int v : adjList.get(u)) {
                if (!visited[v]) {
                    visited[v] = true;
                    queue.enqueue(v);
                }
            }
        }

        return result;
    }
}
```

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Complexity Proof: BFS is strictly $O(V + E)$</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Vertex Processing ($O(V)$)</StepTitle>
    Every vertex is enqueued at most once because we mark it as `visited` *before* enqueuing. Dequeuing and processing a vertex takes $O(1)$ time. Total time for all vertices: $O(V)$.
  </Step>

  <Step number={2}>
    <StepTitle>Edge Processing ($O(E)$)</StepTitle>
    When a vertex $u$ is dequeued, we iterate through its adjacency list `adjList.get(u)`. The time taken is proportional to the degree of $u$, denoted as $\text{deg}(u)$.
  </Step>

  <Step number={3}>
    <StepTitle>Summing the Degrees</StepTitle>
    The total time spent iterating through all adjacency lists across the entire BFS traversal is the sum of the degrees of all visited vertices:
    $$\sum_{u \in V} \text{deg}(u)$$
    By the Handshaking Lemma, the sum of all degrees in an undirected graph is exactly $2E$. Therefore, the total edge processing time is $O(2E) = O(E)$.
  </Step>

  <Step number={4}>
    <StepTitle>Total Complexity</StepTitle>
    Combining the vertex and edge processing times, the total time complexity is strictly $O(V) + O(E) = O(V + E)$.
  </Step>
</StepByStep>
