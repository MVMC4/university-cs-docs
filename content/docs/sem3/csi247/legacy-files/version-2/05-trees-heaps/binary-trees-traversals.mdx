## 5.1 Binary Tree Theorems & Traversals

Understanding the mathematical properties of trees is essential for analyzing algorithm complexity.

<HighlightCard
  variant="neutral"
  title="Theorem 5.1.1: Maximum Nodes at Depth $d$"
  description="The maximum number of nodes at depth $d$ in a binary tree is $2^d$."
>

**Proof by Induction:**
- **Base Case ($d=0$):** The root is at depth 0. $2^0 = 1$. True.
- **Inductive Step:** Assume true for depth $k$. At depth $k+1$, each node at depth $k$ can have at most 2 children. Thus, max nodes at $k+1$ is $2 \times 2^k = 2^{k+1}$. $\blacksquare$

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Theorem 5.1.2: Total Nodes in a Perfect Tree"
  description="A perfect binary tree of height $h$ has exactly $2^{h+1} - 1$ nodes."
>

**Proof:**
A perfect tree has all levels completely filled. The total number of nodes is the sum of nodes at each depth $d$ from $0$ to $h$:
$$N = \sum_{d=0}^h 2^d = 2^0 + 2^1 + \dots + 2^h$$
This is a geometric series with sum:
$$N = \frac{2^{h+1} - 1}{2 - 1} = 2^{h+1} - 1 \quad \blacksquare$$

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Theorem 5.1.3: Height Bounds"
  description="For a binary tree with $N$ nodes, the height $h$ satisfies $\lfloor \log_2 N \rfloor \le h \le N-1$."
>

- **Minimum Height:** Occurs in a perfect tree. $N = 2^{h+1} - 1 \implies h = \log_2(N+1) - 1 \approx \log_2 N$.
- **Maximum Height:** Occurs in a degenerate (skewed) tree, which is effectively a linked list. $h = N-1$.

</HighlightCard>

### Definition 5.1.1: Tree Traversals

- **In-Order:** Left Subtree $\to$ Root $\to$ Right Subtree. Yields sorted order for BSTs.
- **Pre-Order:** Root $\to$ Left Subtree $\to$ Right Subtree. Useful for copying trees.
- **Post-Order:** Left Subtree $\to$ Right Subtree $\to$ Root. Useful for deleting trees.
- **Level-Order (BFS):** Visit nodes level by level using a Queue.

</Card>

<StepByStep>
  <StepByStepTitle>Iterative In-Order Traversal (Using Stack)</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Initialization</StepTitle>
    Create an empty stack. Set `current = root`.
  </Step>

  <Step number={2}>
    <StepTitle>Traverse Left</StepTitle>
    While `current` is not null, push `current` to stack and move `current = current.left`.
  </Step>

  <Step number={3}>
    <StepTitle>Visit and Go Right</StepTitle>
    If `current` is null and stack is not empty:
    1. Pop node from stack.
    2. Visit (print/process) the node.
    3. Set `current = node.right`.
    4. Repeat from Step 2.
  </Step>

  <Step number={4}>
    <StepTitle>Termination</StepTitle>
    The loop terminates when `current` is null and the stack is empty.
  </Step>
</StepByStep>
