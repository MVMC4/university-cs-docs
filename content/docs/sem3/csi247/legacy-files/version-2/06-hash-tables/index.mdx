# Chapter 6: Hash Tables

This chapter explores the mathematics of hash functions, collision resolution strategies, and the theoretical guarantees of open addressing and separate chaining. We will analyze primary and secondary clustering, prove the conditions for guaranteed empty slots in quadratic probing, and understand the amortized cost of rehashing. Finally, we will bridge theory to practice with the Java `hashCode/equals` contract and a complete `SeparateChainingHashMap` implementation.
