## 7.3 Minimum Spanning Trees (MST)

An MST connects all vertices in a graph with the minimum possible total edge weight, without forming any cycles.

<HighlightCard
  variant="neutral"
  title="Theorem 7.3.1: The Cut Property"
  description="For any cut of the graph, the minimum weight edge crossing the cut must belong to the MST."
>

This property is the mathematical foundation for both Prim's and Kruskal's algorithms.

</HighlightCard>

<Card>

### Definition 7.3.2: Prim's Algorithm (Vertex-Based)

- **Strategy:** Grows a single tree from an arbitrary start vertex, always adding the cheapest edge connecting the tree to a non-tree vertex.
- **Data Structure:** Priority Queue (Min-Heap) of edges/vertices.
- **Complexity:** $O((V + E) \\log V)$ with a binary heap.

</Card>

<HighlightCard
  variant="neutral"
  title="Complete Java Implementation: Disjoint Set (Union-Find)"
  description="The critical data structure for Kruskal's algorithm, featuring Path Compression and Union by Rank."
>

```java
class DisjointSet {
    int[] parent;
    int[] rank;

    public DisjointSet(int V) {
        parent = new int[V];
        rank = new int[V];
        for (int i = 0; i < V; i++) {
            parent[i] = i; // Each vertex is its own set initially
        }
    }

    // Find with Path Compression
    public int find(int i) {
        if (parent[i] != i) {
            parent[i] = find(parent[i]); // Path compression: point directly to root
        }
        return parent[i];
    }

    // Union by Rank
    public void union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);

        if (rootX != rootY) {
            if (rank[rootX] < rank[rootY]) {
                parent[rootX] = rootY;
            } else if (rank[rootX] > rank[rootY]) {
                parent[rootY] = rootX;
            } else {
                parent[rootY] = rootX;
                rank[rootX]++; // Increase rank of the new root
            }
        }
    }
}
```
**Crucial Detail:** Path Compression flattens the tree during `find()`, and Union by Rank ensures the tree remains shallow. Together, they reduce the amortized time complexity of both operations to $O(\\alpha(V))$, where $\\alpha$ is the inverse Ackermann function (effectively $O(1)$).

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Complete Java Implementation: Kruskal's Algorithm"
  description="Sorts all edges by weight and uses the Disjoint Set to efficiently detect and prevent cycles."
>

```java
// Assuming Edge class has: int u, int v, int weight
public List<Edge> kruskal() {
    List<Edge> mst = new ArrayList<>();
    List<Edge> edges = getAllEdges(); // Assume this returns all edges in the graph
    
    // 1. Sort all edges by weight (O(E log E))
    edges.sort(Comparator.comparingInt(e -> e.weight));

    // 2. Initialize Disjoint Set
    DisjointSet ds = new DisjointSet(V);

    // 3. Iterate through sorted edges
    for (Edge edge : edges) {
        int rootU = ds.find(edge.u);
        int rootV = ds.find(edge.v);

        // 4. If u and v are not in the same set, adding this edge doesn't form a cycle
        if (rootU != rootV) {
            mst.add(edge);
            ds.union(rootU, rootV); // Merge the sets
        }
    }
    return mst;
}
```
**Complexity:** $O(E \\log E)$ for sorting edges, plus $O(E \\alpha(V))$ for Union-Find. Total: $O(E \\log E)$.

</HighlightCard>
