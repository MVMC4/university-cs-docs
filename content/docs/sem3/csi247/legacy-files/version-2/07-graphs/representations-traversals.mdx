## 7.1 Representations & Traversals

Graphs can be represented in memory using either an Adjacency Matrix or an Adjacency List. The choice dictates the time complexity of fundamental operations.

<HighlightCard
  variant="neutral"
  title="Definition 7.1.1: Graph Representations"
  description="Trade-offs between space and edge lookup time."
>

- **Adjacency Matrix:** $O(V^2)$ space. $O(1)$ edge lookup. Best for dense graphs.
- **Adjacency List:** $O(V + E)$ space. $O(\text{degree})$ edge lookup. Best for sparse graphs.

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Complete Java Implementation: General Adjacency List"
  description="The standard, most common way to represent a graph in Java. Uses a custom Edge class to seamlessly support both unweighted (BFS) and weighted (Dijkstra) algorithms."
>

```java
import java.util.ArrayList;
import java.util.List;

// Custom Edge class to support weighted graphs
public class Edge {
    int to;
    int weight;
    
    public Edge(int to, int weight) {
        this.to = to;
        this.weight = weight;
    }
}

public class Graph {
    private final int V; // Number of vertices
    private final List<List<Edge>> adj; // Adjacency list of Edge objects

    public Graph(int V) {
        this.V = V;
        adj = new ArrayList<>(V);
        for (int i = 0; i < V; i++) {
            adj.add(new ArrayList<>());
        }
    }

    // Add a weighted edge
    public void addEdge(int u, int v, int weight) {
        adj.get(u).add(new Edge(v, weight));
        adj.get(v).add(new Edge(u, weight)); // Comment out for directed graphs
    }

    // Overload for unweighted graphs (defaults to weight 1)
    public void addEdge(int u, int v) {
        addEdge(u, v, 1);
    }
}
```

</HighlightCard>

### Definition 7.1.2: Breadth-First Search (BFS)

- **Data Structure:** Queue.
- **Purpose:** Finds the shortest path in an **unweighted** graph.
- **Time Complexity:** $O(V + E)$.

</Card>

<HighlightCard
  variant="neutral"
  title="Complete Java Implementation: BFS"
  description="Uses a Queue and a boolean visited array to prevent infinite loops and redundant processing."
>

```java
import java.util.LinkedList;
import java.util.Queue;

public void bfs(int start) {
    boolean[] visited = new boolean[V];
    Queue<Integer> queue = new LinkedList<>();

    // Mark the starting node as visited and enqueue it
    visited[start] = true;
    queue.add(start);

    while (!queue.isEmpty()) {
        int u = queue.poll();
        System.out.print(u + " ");

        // Iterate over all Edge objects connected to u
        for (Edge edge : adj.get(u)) {
            int v = edge.to; // Extract destination vertex
            if (!visited[v]) {
                visited[v] = true; // Mark as visited BEFORE enqueuing
                queue.add(v);
            }
        }
    }
}
```
**Crucial Detail:** We mark `visited[v] = true` *before* adding to the queue, not when polling. This prevents the same node from being added to the queue multiple times by different neighbors.

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Definition 7.1.3: Depth-First Search (DFS) & Edge Classification"
  description="DFS uses a Stack (or recursion). It classifies edges into four categories during traversal."
>

1. **Tree Edge:** Edge to an unvisited node.
2. **Back Edge:** Edge to a node currently in the recursion stack (indicates a **cycle** in directed graphs).
3. **Forward Edge:** Edge to a finished descendant in the DFS tree.
4. **Cross Edge:** Edge to a finished node that is neither an ancestor nor a descendant.

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Complete Java Implementation: DFS with Edge Classification & Cycle Detection"
  description="Uses recursion, a visited array, and an inStack (recursion stack) array to explicitly classify edges and detect cycles."
>

```java
private boolean[] visited;      // Tracks discovery time (White/Black)
private boolean[] inStack;      // Tracks nodes currently in the recursion stack (Gray)
private boolean hasCycle;

public void dfsClassify(int start) {
    visited = new boolean[V];
    inStack = new boolean[V];
    hasCycle = false;

    // Handle disconnected components
    for (int i = 0; i < V; i++) {
        if (!visited[i]) {
            dfsUtil(i);
        }
    }
}

private void dfsUtil(int u) {
    visited[u] = true;      // Mark as discovered (Discovery Time)
    inStack[u] = true;      // Push to recursion stack (Gray)

    // Iterate over all Edge objects connected to u
    for (Edge edge : adj.get(u)) {
        int v = edge.to; // Extract destination vertex
        
        if (!visited[v]) {
            // TREE EDGE: Edge to an unvisited node
            dfsUtil(v);
        } else if (inStack[v]) {
            // BACK EDGE: Edge to a node currently in the recursion stack
            // THIS INDICATES A CYCLE!
            hasCycle = true;
        } else {
            // FORWARD OR CROSS EDGE: Edge to a finished node (Black)
        }
    }

    inStack[u] = false;     // Pop from recursion stack (Finish Time / Black)
}
```
**Crucial Detail:** The `inStack` array acts as our "Gray" node tracker. If we encounter a neighbor `v` that is already visited but still `inStack[u] == true`, it means `v` is an ancestor in the current recursion path, forming a Back Edge and proving a cycle exists.

</HighlightCard>
