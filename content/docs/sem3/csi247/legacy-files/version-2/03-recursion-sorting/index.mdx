# Chapter 3: Recursion, Sorting, & Lower Bounds

This chapter transitions from basic algorithmic implementation to rigorous mathematical analysis. We will master the mechanics of the call stack, implement and trace the core sorting algorithms, analyze Divide and Conquer recurrences, formally prove the absolute mathematical limits of comparison-based sorting, and bridge sorting directly to Priority Queues via Heap Sort.
