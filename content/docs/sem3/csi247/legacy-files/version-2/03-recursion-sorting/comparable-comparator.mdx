## 3.3 Comparable & Comparator Interfaces

To sort objects or maintain the invariant of a Binary Search Tree, the data structure must know how to compare elements. Java provides two fundamental interfaces for this: `Comparable<T>` and `Comparator<T>`.

<HighlightCard
  variant="neutral"
  title="Definition 3.3.1: Comparable<T> (Natural Ordering)"
  description="An interface implemented by a class to define its natural, default sorting order."
>

```java
public interface Comparable<T> {
    int compareTo(T o);
}
```

- **Returns:** A negative integer, zero, or a positive integer as this object is less than, equal to, or greater than the specified object.
- **Usage:** `Collections.sort(list)` or `Arrays.sort(array)` on objects that implement `Comparable` (e.g., `Integer`, `String`).
- **Contract:** It is strongly recommended that `compareTo` be consistent with `equals`. (i.e., `a.compareTo(b) == 0` should imply `a.equals(b)`).

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Definition 3.3.2: Comparator<T> (Custom Ordering)"
  description="An interface used to define custom, external sorting orders without modifying the original class."
>

```java
public interface Comparator<T> {
    int compare(T o1, T o2);
}
```

- **Usage:** Passed as an argument to sorting methods: `Arrays.sort(array, comparator)`.
- **Use Case:** Sorting a list of `String` objects by their length instead of alphabetical order.

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Application: Sorting with Comparator</StepByStepTitle>

  <Step number={1}>
    <StepTitle>The Scenario</StepTitle>
    Sort an array of `String` objects by their length in ascending order.
  </Step>

  <Step number={2}>
    <StepTitle>Define the Comparator</StepTitle>
    ```java
    Comparator<String> byLength = (s1, s2) -> Integer.compare(s1.length(), s2.length());
    ```
  </Step>

  <Step number={3}>
    <StepTitle>Apply to Sort</StepTitle>
    ```java
    String[] words = {"apple", "pie", "a", "banana"};
    Arrays.sort(words, byLength);
    // Result: ["a", "pie", "apple", "banana"]
    ```
  </Step>
</StepByStep>

<HighlightCard
  variant="neutral"
  title="Integration with Data Structures"
  description="How Comparable and Comparator are used in Trees and Sorting Algorithms."
>

- **Binary Search Trees:** A BST requires elements to be ordered. The `insert` and `search` methods will call `element.compareTo(node.data)` (if using `Comparable`) or `comparator.compare(element, node.data)` (if using `Comparator`) to decide whether to traverse left or right.
- **Sorting Algorithms:** Algorithms like Merge Sort and Quick Sort will use `compareTo` or `compare` instead of the `<` or `>` operators, allowing them to sort *any* object type generically.

</HighlightCard>
