# CSI247: Data Structures & Algorithms

Welcome to the master curriculum for CSI247. This course is divided into four core modules, taking you from foundational linear structures to advanced algorithmic paradigms.

## Modules

<Card>

Arrays, Matrices, Linked Lists, Stacks, and Queues.

</Card>

<Card>

### [Module 2: Algorithm Analysis, Searching, and Sorting](/docs/sem3/csi247/02-algorithm-analysis-searching-sorting)
Complexity Analysis, Searching Algorithms, Quadratic Sorting, and Logarithmic Sorting.

</Card>

<Card>

### [Module 3: Non-Linear Data Structures](/docs/sem3/csi247/03-non-linear-data-structures)
Tree Fundamentals, BSTs, Balanced Trees (AVL), and Graph Theory.

</Card>

<Card>

### [Module 4: Advanced Traversal & Algorithmic Paradigms](/docs/sem3/csi247/04-advanced-traversal-paradigms)
Graph Traversals, Pathfinding, Greedy Algorithms, and Dynamic Programming.

</Card>
