# Applications of Data Structures

## Decision Guide

| Problem | Structure | Why |
|---------|-----------|-----|
| Fast key lookup | Hash Table | $O(1)$ average access |
| Sorted order | BST | $O(\log n)$ search + ordered traversal |
| Undo/Redo | Stack | LIFO matches action history |
| Task by priority | Priority Queue | Process by urgency |
| Path finding | Graph + BFS/DFS | Model connections |
| Caching with eviction | Hash Map + Doubly Linked List | $O(1)$ access + $O(1)$ LRU eviction |
| Autocomplete/prefix search | Trie | $O(m)$ lookup where $m$ = prefix length |

## Case Study: LRU Cache

Combine Hash Map + Doubly Linked List for $O(1)$ operations.

```ts
// Conceptual structure
class LRUCache<K,V> {
  private map = new Map<K, Node<V>>();
  get(key: K): V | undefined { /* O(1) */ }
  put(key: K, value: V): void { /* O(1) */ }
}
```
