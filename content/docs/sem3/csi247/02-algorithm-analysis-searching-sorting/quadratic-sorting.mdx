## 2.3 Quadratic Sorting ($O(n^2)$)

Quadratic sorting algorithms are intuitive and easy to implement, but their $O(n^2)$ time complexity makes them unsuitable for massive datasets. However, they possess unique properties that make them optimal for specific, constrained scenarios.

<HighlightCard
  variant="neutral"
  title="Definition 2.3.1: In-Place Sorting & Algorithmic Stability"
  description="Critical properties of sorting algorithms."
>

- **In-Place:** The algorithm requires only $O(1)$ auxiliary space, modifying the original array directly without allocating secondary arrays.
- **Stability:** If two elements have equal keys, their relative original order is preserved in the sorted output. Crucial for multi-key sorting.

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Required Skill: Mechanical Traces of Quadratic Sorts</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Bubble Sort (Descending Order Implementation)</StepTitle>
    Repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order.
    ```java
    public void bubbleSortDescending(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            boolean swapped = false;
            for (int j = 0; j < n - i - 1; j++) {
                if (arr[j] < arr[j + 1]) { // Note the '<' for descending
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                    swapped = true;
                }
            }
            if (!swapped) break; // Optimization
        }
    }
    ```
  </Step>

  <Step number={2}>
    <StepTitle>Selection Sort</StepTitle>
    Finds the minimum/maximum element from the unsorted portion and places it at the boundary.
    **Property:** Always performs exactly $O(n^2)$ comparisons, regardless of initial order. Minimizes memory writes ($O(n)$ swaps).
  </Step>

  <Step number={3}>
    <StepTitle>Insertion Sort</StepTitle>
    Builds the sorted array one element at a time by shifting larger elements to the right.
    **Optimization:** Exceptionally fast for *nearly sorted* data. Best Case: $O(n)$.
  </Step>
</StepByStep>
