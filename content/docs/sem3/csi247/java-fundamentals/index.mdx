## What this module covers

- Java source files, bytecode, and the Java Virtual Machine (JVM)
- Primitive types, casting, integer division, and variable scope
- String comparison and manipulation
- Conditional statements and common brace-related mistakes
- Arrays and zero-based indexing
- `for`, `while`, and `do-while` loops
- Console input with `Scanner`
- Input validation with `hasNext...` methods and `try-catch`
- Methods that perform actions or return values
- Basic file creation, writing, and reading

## Study workflow

1. Explore the canvas and run each example by hand.
2. Complete the [practice questions](/docs/sem3/csi247/java-fundamentals/questions).
3. Use the [flashcards and quizzes](/docs/sem3/csi247/java-fundamentals/review) to test recall.
4. Revisit any weak areas before starting recursion.

> This module focuses on the introductory Java material represented in the current course notes. Packages, object-oriented programming, generics, and the Java Collections Framework remain later syllabus topics.
