## 9. Study Strategy

### Recommended Timeline

**Weeks 1-3: Java Foundations & OOP**
- Review Java basics and OOP principles
- Practice Generics and Collections
- Resources: Schildt, Kunal Kushwaha videos

**Weeks 4-5: Algorithmic Thinking**
- Master recursion and Big-O analysis
- Solve 2-3 recursion problems daily
- Resources: CLRS Chapters 1-4, Abdul Bari videos

**Weeks 6-7: Searching & Sorting**
- Implement all sorting algorithms
- Understand when to use each
- Resources: Sedgewick, VisuAlgo animations

**Weeks 8-9: Java Collections**
- Master List, Set, Map, Queue
- Understand internals of each
- Resources: Oracle docs, Java Brains videos

**Weeks 10-15: Custom Implementations**
- Build each data structure from scratch
- Focus on LinkedList, Stack, Queue, Hash Table, Tree, Graph
- Resources: CLRS, William Fiset videos, VisuAlgo

### Daily Practice Routine

1. **Learn** (30 min): Watch video or read textbook section
2. **Implement** (30 min): Code the data structure/algorithm from scratch
3. **Practice** (1 hour): Solve 2-3 LeetCode problems
4. **Review** (15 min): Analyze time/space complexity

### Effective Study Techniques

**1. Active Recall**
- Implement algorithms from memory
- Explain concepts out loud

**2. Spaced Repetition**
- Review topics at increasing intervals
- Use Anki for algorithm complexities

**3. Pattern Recognition**
- Group problems by pattern
- Focus on understanding, not memorization

**4. Teach Others**
- Write explanations
- Help classmates understand
