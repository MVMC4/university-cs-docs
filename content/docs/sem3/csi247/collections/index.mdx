# Java Collections Framework

<span className="inline-flex items-center rounded-xl bg-fd-muted px-2.5 text-sm font-medium text-fd-muted-foreground ring-1 ring-inset ring-fd-border ">
  Last Updated: July 11, 2026
</span>

This comprehensive visual map covers the Java Collections Framework, including:
- **Core Interfaces:** Iterable, Collection, List, Set, and Map hierarchies.
- **List Implementations:** ArrayList (dynamic arrays) vs. LinkedList (doubly-linked nodes).
- **Set Implementations:** HashSet (hash tables), TreeSet (Red-Black trees), and LinkedHashSet.
- **Map Implementations:** HashMap, TreeMap, and ConcurrentHashMap for thread safety.
- **Utilities:** Iterators, Comparators, and the Collections utility class.
