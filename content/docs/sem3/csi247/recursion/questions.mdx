# Practice Questions: Recursion & Paradigms

<ExamQuestion title="Question 1: Call Stack & Space Complexity [10 Marks]">
  <SubQuestion part="a" prompt={<>Draw the call stack for a recursive function computing the factorial of 4. What is the maximum depth and space complexity? [5]</>} solution={<>The stack builds up: fact(4) then fact(3) then fact(2) then fact(1). Maximum depth is 4. Space complexity is O(N) due to the call stack frames.</>} />
  <SubQuestion part="b" prompt={<>Explain why a missing base case results in a StackOverflowError. [5]</>} solution={<>Without a base case, the function infinitely calls itself. Each call allocates a new frame on the call stack. Eventually, the stack exceeds its allocated memory limit, crashing the program.</>} />
</ExamQuestion>

<ExamQuestion title="Question 2: Backtracking & Pruning [12 Marks]">
  <SubQuestion part="a" prompt={<>Explain the concept of 'pruning' in a backtracking algorithm like N-Queens. [4]</>} solution={<>Pruning is the act of abandoning a recursive branch early because it violates a constraint, preventing the algorithm from exploring an entire invalid subtree.</>} />
  <SubQuestion part="b" prompt={<>If generating all permutations of a string of length N, what is the time complexity? Why? [4]</>} solution={<>O(N * N!). There are N! permutations, and copying or building each string takes O(N) time.</>} />
  <SubQuestion part="c" prompt={<>How does backtracking differ from standard Divide and Conquer? [4]</>} solution={<>Divide and Conquer breaks problems into independent subproblems and combines them. Backtracking explores a state-space tree, making choices, and undoing them if they lead to dead ends.</>} />
</ExamQuestion>

<ExamQuestion title="Question 3: Dynamic Programming vs Memoization [10 Marks]">
  <SubQuestion part="a" prompt={<>What are the two required properties for a problem to be solvable with Dynamic Programming? [4]</>} solution={<>1. Overlapping Subproblems (the same subproblems are solved multiple times). 2. Optimal Substructure (the optimal solution contains optimal solutions to subproblems).</>} />
  <SubQuestion part="b" prompt={<>Compare Top-Down Memoization and Bottom-Up Tabulation in terms of space and time complexity. [6]</>} solution={<>Both have the same time complexity. Top-Down uses recursion and the call stack (O(N) space overhead). Bottom-Up uses iteration and an array, avoiding call stack overhead and often allowing space optimization.</>} />
</ExamQuestion>
