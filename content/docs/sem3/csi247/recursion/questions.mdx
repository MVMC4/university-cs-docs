<ExamQuestion title="Question 2: Divide and Conquer (Majority Element) [12 Marks]">
  <SubQuestion part="a" prompt={<>Design a D&C algorithm to find the majority element in O(N log N) time without extra space. [6]</>} solution={<>Split array in half. Recursively find majority in left and right. If both return the same element, that's the candidate. Otherwise, count occurrences of both candidates in the full range.</>} />
  <SubQuestion part="b" prompt={<>Explain the merge step if left returns X and right returns Y. [4]</>} solution={<>Scan the combined array to count exact occurrences of X and Y. Return whichever exceeds N/2, or null if neither does.</>} />
  <SubQuestion part="c" prompt={<>Write the recurrence relation. [2]</>} solution={<>T(n) = 2T(n/2) + O(n), which solves to O(n log n).</>} />
</ExamQuestion>

<ExamQuestion title="Question 3: Grid Traversal with Constraints (Memoization) [15 Marks]">
  <SubQuestion part="a" prompt={<>Write a top-down recursive method with memoization for max battery level on an M x N grid with magnets and prime-number recharges. [10]</>} solution={<>State: (r, c, current_battery). Memoize based on (r, c). Return -infinity if magnet or battery &lt; 0. Add +2 if (r+c) is prime.</>} />
  <SubQuestion part="b" prompt={<>What are the dimensions of the memo table? [3]</>} solution={<>M x N. We only need to memoize the maximum battery possible when reaching cell (r, c), assuming we arrived with sufficient battery.</>} />
  <SubQuestion part="c" prompt={<>Why might pure recursion fail on a 1000x1000 grid? [2]</>} solution={<>StackOverflowError due to depth, and Time Limit Exceeded due to overlapping subproblems (2^(M+N) paths without memoization).</>} />
</ExamQuestion>
