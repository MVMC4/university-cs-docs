# Graphs

This comprehensive visual map covers Graph Algorithms, including:
- **Representations:** Adjacency Matrices vs. Adjacency Lists (Space/Time trade-offs).
- **Traversals:** Breadth-First Search (BFS) and Depth-First Search (DFS).
- **Shortest Paths:** Dijkstra's (non-negative weights), Bellman-Ford (negative weights), and Floyd-Warshall (all-pairs).
- **Minimum Spanning Trees:** Kruskal's (Union-Find) and Prim's algorithms.
- **Topological Sort:** Kahn's Algorithm and DFS-based approaches for DAGs.
