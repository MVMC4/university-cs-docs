# Practice Questions: Graphs

<ExamQuestion title="Question 1: Constrained BFS (Social Network) [12 Marks]">
  <SubQuestion part="a" prompt={<>Write BFS to find shortest path from User A to User B. [6]</>} solution={<>Standard BFS using a Queue and a visited set. Track distances in a HashMap.</>} />
  <SubQuestion part="b" prompt={<>Modify to exclude intermediate users where isPrivate == true. [4]</>} solution={<>When iterating neighbors, add an <code>if (!neighbor.isPrivate)</code> check before enqueuing. Start and end nodes are exempt from this check.</>} />
  <SubQuestion part="c" prompt={<>What data structure reconstructs the actual path? [2]</>} solution={<>A <code>parent</code> HashMap that maps each visited node to the node that discovered it.</>} />
</ExamQuestion>

<ExamQuestion title="Question 2: Dijkstra's with State Constraints [15 Marks]">
  <SubQuestion part="a" prompt={<>Find shortest distance from S to T with total tollCost &le; B. Why does standard Dijkstra fail? [4]</>} solution={<>Standard Dijkstra assumes the shortest path to a node is always optimal. Here, a slightly longer path might leave more budget for future edges, making it the true optimal path.</>} />
  <SubQuestion part="b" prompt={<>Propose modified Dijkstra. What does the PQ state look like? [6]</>} solution={<>State: (current_node, current_distance, current_toll). PQ orders by distance. Visited array becomes 2D: visited[node][toll_spent].</>} />
  <SubQuestion part="c" prompt={<>New time and space complexity? [5]</>} solution={<>Time: O(E * B * log(V * B)). Space: O(V * B) for the distance/visited matrix.</>} />
</ExamQuestion>

<ExamQuestion title="Question 3: Topological Sort & Course Scheduling [12 Marks]">
  <SubQuestion part="a" prompt={<>Use Kahn's Algorithm to detect cycles in a DAG. [6]</>} solution={<>Calculate in-degrees. Enqueue nodes with 0 in-degree. Process and decrement neighbors. If processed count != total nodes, a cycle exists.</>} />
  <SubQuestion part="b" prompt={<>Modify to find minimum semesters if max K courses per semester. [6]</>} solution={<>Process the queue in batches of size K. Each batch represents one semester. Increment semester counter after each batch.</>} />
</ExamQuestion>

<ExamQuestion title="Question 4: Kruskal's MST with Forbidden Edges [10 Marks]">
  <SubQuestion part="a" prompt={<>Trace Kruskal's using DSU. Show parent and rank arrays. [6]</>} solution={<>Sort edges. Iterate. Use find() to check sets. If different, union() and add to MST. Path compression keeps find() near O(1).</>} />
  <SubQuestion part="b" prompt={<>How to handle forbidden edge between Island 1 and 2? [4]</>} solution={<>Simply add an <code>if (edge connects 1 and 2) continue;</code> check before the DSU union step. The algorithm will naturally skip it and pick the next cheapest valid edge.</>} />
</ExamQuestion>
