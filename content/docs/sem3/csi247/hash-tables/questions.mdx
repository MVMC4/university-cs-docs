# Practice Questions: Hash Tables

<ExamQuestion title="Question 1: Linear Probing & Deletion [12 Marks]">
  <SubQuestion part="a" prompt={<>Insert 12, 25, 38, 51, 64 into array of size 7. Hash = k mod 7. Draw array. [5]</>} solution={<>12-&gt;5, 25-&gt;4, 38-&gt;3, 51-&gt;2, 64-&gt;1. Array: [null, 64, 51, 38, 25, 12, null].</>} />
  <SubQuestion part="b" prompt={<>Why does setting array[3]=null break search for keys that collided with 38? [3]</>} solution={<>Search probes sequentially. If it hits null, it assumes the key doesn't exist and stops, even if the key was placed further down due to prior collisions.</>} />
  <SubQuestion part="c" prompt={<>Implement Tombstone approach. How do search and insert handle it? [4]</>} solution={<>Search treats tombstones as occupied (keeps probing). Insert treats tombstones as empty (can overwrite it).</>} />
</ExamQuestion>

<ExamQuestion title="Question 2: Separate Chaining & Rehashing [12 Marks]">
  <SubQuestion part="a" prompt={<>Insert 10, 22, 34, 46, 58 into capacity 4. Hash = k mod 4. Draw lists. [4]</>} solution={<>All hash to 2. Array[2] is a linked list: 10 -&gt; 22 -&gt; 34 -&gt; 46 -&gt; 58.</>} />
  <SubQuestion part="b" prompt={<>Write <code>rehash()</code> when load factor hits 1.0. Double capacity. [6]</>} solution={<>Create new array of size 8. Iterate all nodes in old lists, recalculate hash % 8, and insert into new array.</>} />
  <SubQuestion part="c" prompt={<>Worst-case vs amortized time of put()? [2]</>} solution={<>Worst-case O(N) if rehash triggers or all keys collide. Amortized O(1) over N operations.</>} />
</ExamQuestion>

<ExamQuestion title="Question 3: Designing Hash Functions [8 Marks]">
  <SubQuestion part="a" prompt={<>Why is polynomial rolling hash poor for Chess board states? [4]</>} solution={<>Symmetric boards or boards with shifted pieces might produce identical hashes, causing massive collisions.</>} />
  <SubQuestion part="b" prompt={<>Explain Zobrist Hashing. How to initialize and compute? [4]</>} solution={<>Initialize a 3D array of random 64-bit integers [piece_type][color][square]. To hash a board, XOR the random numbers for every piece currently on the board.</>} />
</ExamQuestion>

<ExamQuestion title="Question 4: Bloom Filters [10 Marks]">
  <SubQuestion part="a" prompt={<>Explain add() and mightContain() using k hash functions and bit array. [4]</>} solution={<>add(): Hash string k times, set those k indices to 1. mightContain(): Hash k times, return true only if ALL k indices are 1.</>} />
  <SubQuestion part="b" prompt={<>Why false positives but never false negatives? [3]</>} solution={<>Bits are only ever set to 1, never 0. If a string was added, its bits are 1. Another string might accidentally share those exact k bits (false positive), but the original string will always find its bits set (no false negative).</>} />
  <SubQuestion part="c" prompt={<>Calculate false positive probability for n=1M, m=10M, k=3. [3]</>} solution={<>Formula: (1 - e^(-kn/m))^k. Plug in values to get approx 1.4%.</>} />
</ExamQuestion>
