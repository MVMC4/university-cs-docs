# Arrays vs Linked Lists

Both are linear data structures, but they store data in memory very differently, leading to different performance trade-offs.

## Memory Layout Comparison

## Arrays
- **Memory**: Contiguous block of memory.
- **Access**: $O(1)$ random access via index.
- **Insertion/Deletion**: $O(n)$ in the worst case (requires shifting elements).
- **Cache Locality**: Excellent, due to contiguous memory.

## Linked Lists
- **Memory**: Non-contiguous; nodes are scattered and linked via pointers.
- **Access**: $O(n)$ sequential access (must traverse from the head).
- **Insertion/Deletion**: $O(1)$ if you already have a reference to the node.
- **Cache Locality**: Poor, due to scattered memory allocation.

## Complexity Comparison

| Operation | Array | Singly Linked List | Doubly Linked List |
|-----------|-------|-------------------|-------------------|
| Access by index | $O(1)$ | $O(n)$ | $O(n)$ |
| Search | $O(n)$ | $O(n)$ | $O(n)$ |
| Insert at head | $O(1)$* | $O(1)$ | $O(1)$ |
| Insert at tail | $O(1)$* | $O(n)$ | $O(1)$† |
| Delete by value | $O(n)$ | $O(n)$ | $O(n)$ |
| Space overhead | None | 1 pointer/node | 2 pointers/node |

*\*Amortized with dynamic resizing*  
*†With tail pointer*
