## Before you start

You should be able to:

- trace linear and binary search and state when each can be used;
- trace one or more passes of Bubble, Selection, and Insertion Sort;
- show the split and merge stages of Merge Sort;
- compare best- and worst-case time complexities;
- explain stability, auxiliary space, and when an algorithm is a sensible choice.
