This comprehensive visual map covers Sorting and Searching, including:
- **Comparison Sorts:** Quick Sort (partitioning), Merge Sort (divide & conquer), and Heap Sort.
- **Non-Comparison Sorts:** Counting Sort and Radix Sort (linear time complexities).
- **Searching:** Binary Search, Rotated Array Search, and Interpolation Search.
- **Properties:** Stability, in-place constraints, and the Omega(N log N) lower bound proof.
