These notes cover the algorithms in the supplied Sorting & Searching study map:
- **Searching Algorithms:** Linear search and Binary search mechanics.
- **Sorting Algorithms:** Bubble sort, Selection sort, Insertion sort, and Merge sort.
- **Algorithm Choice:** Requirements, time complexity, stability, memory use, and suitable use cases.

## Quick comparison

| Algorithm | Requirement or main idea | Best time | Worst time | Extra space |
| :--- | :--- | :---: | :---: | :---: |
| Linear Search | Check each element in order | O(1) | O(N) | O(1) |
| Binary Search | Data must be sorted; halve the range | O(1) | O(log N) | O(1) iterative |
| Bubble Sort | Swap adjacent out-of-order values | O(N) optimized | O(N^2) | O(1) |
| Selection Sort | Select the minimum remaining value | O(N^2) | O(N^2) | O(1) |
| Insertion Sort | Insert each value into the sorted section | O(N) | O(N^2) | O(1) |
| Merge Sort | Split, sort, and merge halves | O(N log N) | O(N log N) | O(N) for arrays |

> Use linear search for one search in unsorted data. Use binary search when the data is already sorted and searched repeatedly.
