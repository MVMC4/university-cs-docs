# Hashing

Hash functions map keys to array indices for fast lookup.

```ts
function hash(key: string, size: number): number {
  let h = 0;
  for (let i = 0; i < key.length; i++) {
    h = (h * 31 + key.charCodeAt(i)) % size;
  }
  return h;
}
```

### 1. Chaining (Separate Chaining)
Each bucket holds a linked list of entries.

```
Index 0 → [key1] → [key4]
Index 1 → [key2]
Index 2 → [key3] → [key5] → [key7]
```

**Complexity:**
- Average: $O(1 + \alpha)$ where $\alpha = n/m$ (load factor)
- Worst: $O(n)$ if all keys collide

### 2. Open Addressing
Find another empty slot within the table.

| Method | Probe Sequence | Pros | Cons |
|--------|---------------|------|------|
| Linear Probing | $h(k) + i$ | Simple, cache-friendly | Primary clustering |
| Quadratic Probing | $h(k) + i^2$ | Reduces clustering | Secondary clustering |
| Double Hashing | $h_1(k) + i \cdot h_2(k)$ | Minimal clustering | More computation |

## Load Factor & Rehashing

$$ \alpha = \frac{n}{m} $$

- $n$ = number of elements, $m$ = table size
- Rehash when $\alpha > 0.7$ to maintain performance
- Rehashing: Create larger table, re-insert all elements

## Complexity Summary

| Operation | Average Case | Worst Case |
|-----------|-------------|------------|
| Search | $O(1)$ | $O(n)$ |
| Insert | $O(1)$ | $O(n)$ |
| Delete | $O(1)$ | $O(n)$ |
