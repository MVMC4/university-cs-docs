# Stacks and Queues

Linear data structures where insertion and deletion follow specific rules.

## Stacks (LIFO - Last In, First Out)

```ts
interface Stack<T> {
  push(item: T): void;      // O(1)
  pop(): T | undefined;     // O(1)
  peek(): T | undefined;    // O(1)
  isEmpty(): boolean;       // O(1)
}
```

**Operations:**
- `push`: Add element to top
- `pop`: Remove and return top element
- `peek`: View top element without removing

**Applications:**
- Function call stack (recursion)
- Undo/Redo functionality
- Expression evaluation (postfix notation)
- Depth-First Search traversal

## Queues (FIFO - First In, First Out)

```ts
interface Queue<T> {
  enqueue(item: T): void;   // O(1)
  dequeue(): T | undefined; // O(1)
  front(): T | undefined;   // O(1)
  isEmpty(): boolean;       // O(1)
}
```

**Operations:**
- `enqueue`: Add element to rear
- `dequeue`: Remove and return front element
- `front`: View front element without removing

- Task scheduling (CPU, print jobs)
- Breadth-First Search traversal
- Buffer management (keyboard, network packets)

## Complexity Comparison

| Operation | Stack (Array) | Queue (Linked) | Circular Queue |
|-----------|--------------|----------------|----------------|
| Push/Enqueue | O(1)* | O(1) | O(1) |
| Pop/Dequeue | O(1) | O(1) | O(1) |
| Peek/Front | O(1) | O(1) | O(1) |
| Space | O(n) | O(n) | O(n) |

*\*Amortized with dynamic resizing*
