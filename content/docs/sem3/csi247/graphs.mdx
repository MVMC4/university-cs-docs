# Graphs Implementation

Graphs are like maps of connections. They show how things are related to each other - like friends on social media, cities connected by roads, or web pages linked together.

> **Why Learn This?**
> Imagine you're building:
> - **GPS navigation**: Find shortest route between cities
> - **Social network**: Suggest friends of friends
> - **Flight booking**: Find cheapest path with connections
> 
> Graphs help you solve real-world connection problems!

## Part 1: Understanding Graphs - The Basics

### What is a Graph?

**Simple Explanation**: A graph is a collection of points (called vertices or nodes) connected by lines (called edges).

**Real-World Examples**:
- **Social network**: People are nodes, friendships are edges
- **Road map**: Cities are nodes, roads are edges
- **Internet**: Websites are nodes, hyperlinks are edges
- **Flight network**: Airports are nodes, flights are edges

### Graph Terminology

**Key Terms**:
1. **Vertex (Node)**: A point in the graph
2. **Edge**: A connection between two vertices
3. **Directed**: Edges have direction (one-way)
4. **Undirected**: Edges have no direction (two-way)
5. **Weighted**: Edges have values (distance, cost, time)
6. **Path**: Sequence of edges connecting vertices
7. **Cycle**: Path that starts and ends at same vertex

**Visual Example**:

```
Undirected Graph:
    A --- B
    |   / |
    |  /  |
    C --- D

Vertices: A, B, C, D
Edges: A-B, A-C, B-C, B-D, C-D

Directed Graph:
    A → B
    ↓ ↙ ↓
    C ← D

Edges: A→B, A→C, B→C, B→D, D→C
```

## Part 2: Graph Representations

### How do we store graphs in code?

There are two main ways to represent graphs:

### Method 1: Adjacency Matrix

**Simple Explanation**: A 2D grid (table) where rows and columns are vertices. If there's an edge from vertex i to vertex j, mark cell [i][j].

**Real-World Analogy**: A multiplication table showing which numbers are connected.

**Example**:

```
Graph:
    A --- B
    |   / |
    |  /  |
    C --- D

Adjacency Matrix (1 = connected, 0 = not connected):
      A  B  C  D
    A 0  1  1  0
    B 1  0  1  1
    C 1  1  0  1
    D 0  1  1  0

Row A: Connected to B and C
Row B: Connected to A, C, and D
```

**Code**:

```java
int vertices = 4;
int[][] matrix = new int[vertices][vertices];

// Add edge between A (0) and B (1)
matrix[0][1] = 1;
matrix[1][0] = 1;  // For undirected graph

// Check if A and C are connected
if (matrix[0][2] == 1) {
    System.out.println("A and C are connected");
}
```

**Speed**:
- **Check if edge exists**: O(1) - instant lookup
- **Find all neighbors**: O(V) - check entire row
- **Space**: O(V²) - V × V grid

**When to use**:
- Dense graphs (many edges)
- Need fast edge lookup
- Small number of vertices

---

### Method 2: Adjacency List

**Simple Explanation**: For each vertex, keep a list of its neighbors.

**Real-World Analogy**: A phone book listing who each person knows.

**Example**:

```
Graph:
    A --- B
    |   / |
    |  /  |
    C --- D

Adjacency List:
A: [B, C]
B: [A, C, D]
C: [A, B, D]
D: [B, C]

A is connected to B and C
B is connected to A, C, and D
```

**Code**:

```java
int vertices = 4;
List<List<Integer>> adjList = new ArrayList<>();

// Initialize lists
for (int i = 0; i < vertices; i++) {
    adjList.add(new ArrayList<>());
}

// Add edge between A (0) and B (1)
adjList.get(0).add(1);  // A → B
adjList.get(1).add(0);  // B → A (undirected)

// Get neighbors of A
List<Integer> neighbors = adjList.get(0);  // [1] = [B]
```

**Speed**:
- **Check if edge exists**: O(V) - search through list
- **Find all neighbors**: O(1) - just get the list
- **Space**: O(V + E) - V lists + E edges

**When to use**:
- Sparse graphs (few edges)
- Need to iterate neighbors often
- Large number of vertices

---

### Matrix vs List Comparison

| Feature | Adjacency Matrix | Adjacency List |
|---------|------------------|----------------|
| **Space** | O(V²) | O(V + E) |
| **Check edge** | O(1) - instant | O(V) - search |
| **Find neighbors** | O(V) - check row | O(1) - get list |
| **Add edge** | O(1) | O(1) |
| **Best for** | Dense graphs | Sparse graphs |
| **Example** | Complete graph | Social network |

**Rule of Thumb**:
- Use **Matrix** when graph is dense (many edges, close to V²)
- Use **List** when graph is sparse (few edges, much less than V²)

## Part 3: Graph Traversal Algorithms

### How do we visit all nodes in a graph?

There are two main ways to explore a graph:

### 1. Breadth-First Search (BFS)

**Simple Explanation**: Explore level by level, like ripples in water. Visit all neighbors first, then their neighbors.

**Real-World Analogy**: Spreading news - you tell all your friends, then they tell all their friends.

**How it works**:
1. Start at a node
2. Visit all its neighbors
3. Then visit all their neighbors
4. Continue until all nodes visited

**Uses a Queue** (First In, First Out)

**Step-by-Step Example**:

```
Graph:
    0 --- 1
    |   / |
    |  /  |
    2 --- 3

BFS starting from 0:

Step 1: Visit 0, add neighbors 1, 2 to queue
Queue: [1, 2]
Visited: {0}

Step 2: Visit 1 (front of queue), add neighbor 3
Queue: [2, 3]
Visited: {0, 1}

Step 3: Visit 2 (front of queue), neighbor 3 already in queue
Queue: [3]
Visited: {0, 1, 2}

Step 4: Visit 3 (front of queue), no new neighbors
Queue: []
Visited: {0, 1, 2, 3}

Result: 0 → 1 → 2 → 3
```

**Code**:

```java
public void bfs(int start, List<List<Integer>> adjList) {
    boolean[] visited = new boolean[adjList.size()];
    Queue<Integer> queue = new LinkedList<>();
    
    // Start from given node
    visited[start] = true;
    queue.add(start);
    
    while (!queue.isEmpty()) {
        int node = queue.poll();  // Get front of queue
        System.out.print(node + " ");
        
        // Add all unvisited neighbors to queue
        for (int neighbor : adjList.get(node)) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                queue.add(neighbor);
            }
        }
    }
}
```

**Speed**: O(V + E) - visit each vertex and edge once

**When to use**:
- Find shortest path in unweighted graph
- Level-order traversal
- Check if graph is connected
- Find all nodes at distance k

---

### 2. Depth-First Search (DFS)

**Simple Explanation**: Explore as deep as possible before backtracking. Like exploring a maze - go down one path until you hit a dead end, then backtrack.

**Real-World Analogy**: Exploring a cave - go deep into one tunnel before trying another.

**How it works**:
1. Start at a node
2. Visit one neighbor
3. Visit one of its neighbors
4. Continue until dead end
5. Backtrack and try other paths

**Uses a Stack** (Last In, First Out) or Recursion

**Step-by-Step Example**:

```
Graph:
    0 --- 1
    |   / |
    |  /  |
    2 --- 3

DFS starting from 0 (recursive):

Step 1: Visit 0
Step 2: Go to neighbor 1
Step 3: From 1, go to neighbor 3 (0 already visited)
Step 4: From 3, go to neighbor 2 (1 already visited)
Step 5: From 2, all neighbors visited, backtrack
Step 6: Back to 3, all neighbors visited, backtrack
Step 7: Back to 1, all neighbors visited, backtrack
Step 8: Back to 0, all neighbors visited, done

Result: 0 → 1 → 3 → 2
```

**Code (Recursive)**:

```java
public void dfs(int node, List<List<Integer>> adjList, boolean[] visited) {
    visited[node] = true;
    System.out.print(node + " ");
    
    // Visit all unvisited neighbors
    for (int neighbor : adjList.get(node)) {
        if (!visited[neighbor]) {
            dfs(neighbor, adjList, visited);
        }
    }
}

// Usage:
boolean[] visited = new boolean[adjList.size()];
dfs(0, adjList, visited);
```

**Code (Iterative with Stack)**:

```java
public void dfsIterative(int start, List<List<Integer>> adjList) {
    boolean[] visited = new boolean[adjList.size()];
    Stack<Integer> stack = new Stack<>();
    
    stack.push(start);
    
    while (!stack.isEmpty()) {
        int node = stack.pop();
        
        if (!visited[node]) {
            visited[node] = true;
            System.out.print(node + " ");
            
            // Add neighbors to stack (reverse order for same result as recursive)
            for (int i = adjList.get(node).size() - 1; i >= 0; i--) {
                int neighbor = adjList.get(node).get(i);
                if (!visited[neighbor]) {
                    stack.push(neighbor);
                }
            }
        }
    }
}
```

**Speed**: O(V + E) - visit each vertex and edge once

**When to use**:
- Cycle detection
- Topological sort
- Path finding
- Maze solving
- Connected components

---

### BFS vs DFS Comparison

| Feature | BFS | DFS |
|---------|-----|-----|
| **Data Structure** | Queue | Stack (or recursion) |
| **Exploration** | Level by level | Depth first |
| **Shortest path** | Yes (unweighted) | No |
| **Memory** | O(V) - store level | O(V) - recursion stack |
| **Use when** | Shortest path, levels | Cycle detection, paths |

## Part 4: Shortest Path Algorithms

### How do we find the shortest path?

### 1. Dijkstra's Algorithm

**Simple Explanation**: Find shortest path from one node to all others. Always visit the closest unvisited node next.

**Real-World Analogy**: GPS navigation - find shortest route from your location to all destinations.

**How it works**:
1. Start at source node, distance = 0
2. Mark all other nodes as distance = infinity
3. Visit the unvisited node with smallest distance
4. Update distances to its neighbors
5. Repeat until all nodes visited

**Uses a Priority Queue** (min-heap)

**Important**: Only works with positive weights!

**Step-by-Step Example**:

```
Graph (numbers are edge weights):
    0 --4-- 1
    |      / |
    2    2   3
    |  /     |
    3 --1-- 2

Find shortest path from 0:

Initial:
Distances: [0, ∞, , ∞]
Priority Queue: [(0, 0)]  // (distance, node)

Step 1: Visit 0 (distance 0)
Update neighbors:
- 1: 0 + 4 = 4
- 3: 0 + 2 = 2
Distances: [0, 4, ∞, 2]
Queue: [(2, 3), (4, 1)]

Step 2: Visit 3 (distance 2)
Update neighbors:
- 1: min(4, 2+2) = 4 (no change)
- 2: 2 + 1 = 3
Distances: [0, 4, 3, 2]
Queue: [(3, 2), (4, 1)]

Step 3: Visit 2 (distance 3)
Update neighbors:
- 1: min(4, 3+2) = 4 (no change)
Distances: [0, 4, 3, 2]
Queue: [(4, 1)]

Step 4: Visit 1 (distance 4)
No updates needed

Final distances from 0:
To 0: 0
To 1: 4 (path: 0→1)
To 2: 3 (path: 0→3→2)
To 3: 2 (path: 0→3)
```

**Code**:

```java
public int[] dijkstra(int start, List<List<int[]>> adjList) {
    int n = adjList.size();
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    
    // Priority queue: (distance, node)
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.add(new int[]{0, start});
    
    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int d = curr[0];
        int node = curr[1];
        
        // Skip if we've found a better path already
        if (d > dist[node]) continue;
        
        // Update neighbors
        for (int[] edge : adjList.get(node)) {
            int neighbor = edge[0];
            int weight = edge[1];
            
            if (dist[node] + weight < dist[neighbor]) {
                dist[neighbor] = dist[node] + weight;
                pq.add(new int[]{dist[neighbor], neighbor});
            }
        }
    }
    
    return dist;
}
```

**Speed**: O((V + E) log V) with priority queue

**When to use**:
- Shortest path in weighted graph
- GPS navigation
- Network routing
- **Only with positive weights!**

### 2. Bellman-Ford Algorithm

**Simple Explanation**: Find shortest path even with negative weights. Relax all edges V-1 times.

**Real-World Analogy**: Finding cheapest flight route even with discounts (negative costs).

**How it works**:
1. Start with source distance = 0, others = infinity
2. For V-1 iterations:
   - For each edge (u, v) with weight w:
     - If dist[u] + w < dist[v], update dist[v]
3. Check for negative cycles

**Step-by-Step Example**:

```
Graph with negative weight:
    0 --4-- 1
    |      / 
    2    -3
    |  /   
    3

Iterations (V-1 = 3):

Initial: [0, ∞, ∞, ∞]

Iteration 1:
Edge 0→1 (4): dist[1] = min(∞, 0+4) = 4
Edge 0→3 (2): dist[3] = min(∞, 0+2) = 2
Edge 3→1 (-3): dist[1] = min(4, 2+(-3)) = -1
Result: [0, -1, ∞, 2]

Iteration 2:
No more improvements
Result: [0, -1, ∞, 2]

Iteration 3:
No more improvements
Final: [0, -1, ∞, 2]
```

**Code**:

```java
public int[] bellmanFord(int start, int[][] edges, int n) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    
    // Relax all edges V-1 times
    for (int i = 0; i < n - 1; i++) {
        for (int[] edge : edges) {
            int u = edge[0];
            int v = edge[1];
            int w = edge[2];
            
            if (dist[u] != Integer.MAX_VALUE && 
                dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
            }
        }
    }
    
    // Check for negative cycles
    for (int[] edge : edges) {
        int u = edge[0];
        int v = edge[1];
        int w = edge[2];
        
        if (dist[u] != Integer.MAX_VALUE && 
            dist[u] + w < dist[v]) {
            System.out.println("Negative cycle detected!");
            return null;
        }
    }
    
    return dist;
}
```

**Speed**: O(V × E)

**When to use**:
- Graphs with negative weights
- Detect negative cycles
- Slower than Dijkstra but more versatile

### 3. Floyd-Warshall Algorithm

**Simple Explanation**: Find shortest paths between ALL pairs of nodes.

**Real-World Analogy**: Calculate distances between all pairs of cities.

**How it works**:
1. Create distance matrix
2. For each intermediate node k:
   - For each pair (i, j):
     - If going through k is shorter, update

**Code**:

```java
public int[][] floydWarshall(int[][] graph, int n) {
    int[][] dist = new int[n][n];
    
    // Initialize with graph
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            dist[i][j] = graph[i][j];
        }
    }
    
    // Try all intermediate nodes
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
    
    return dist;
}
```

**Speed**: O(V³)

**When to use**:
- All-pairs shortest paths
- Small graphs (V < 500)
- Dense graphs

## Part 5: Advanced Graph Algorithms

### 1. Topological Sort

**Simple Explanation**: Order nodes in a directed graph so that for every edge u→v, u comes before v.

**Real-World Analogy**: Course prerequisites - take course A before course B if A is required for B.

**Use Case**: Task scheduling, build systems, course prerequisites

**Kahn's Algorithm (BFS-based)**:

**How it works**:
1. Calculate in-degree (number of incoming edges) for each node
2. Add all nodes with in-degree 0 to queue
3. While queue not empty:
   - Remove node, add to result
   - Decrease in-degree of its neighbors
   - If neighbor's in-degree becomes 0, add to queue
4. If result contains all nodes, success! Otherwise, cycle exists.

**Step-by-Step Example**:

```
Graph (course prerequisites):
    0 → 1 → 3
    ↓   ↓
    2 → 4

In-degrees:
0: 0
1: 1 (from 0)
2: 1 (from 0)
3: 1 (from 1)
4: 2 (from 1, 2)

Step 1: Add 0 to queue (in-degree 0)
Queue: [0]
Result: []

Step 2: Process 0
Result: [0]
Decrease in-degrees of 1, 2
Queue: [1, 2]

Step 3: Process 1
Result: [0, 1]
Decrease in-degrees of 3, 4
Queue: [2, 3]

Step 4: Process 2
Result: [0, 1, 2]
Decrease in-degree of 4
Queue: [3, 4]

Step 5: Process 3
Result: [0, 1, 2, 3]
Queue: [4]

Step 6: Process 4
Result: [0, 1, 2, 3, 4]
Queue: []

Topological order: 0 → 1 → 2 → 3 → 4
```

**Code**:

```java
public int[] topologicalSort(int n, int[][] edges) {
    List<List<Integer>> adj = new ArrayList<>();
    int[] inDegree = new int[n];
    
    for (int i = 0; i < n; i++) {
        adj.add(new ArrayList<>());
    }
    
    for (int[] edge : edges) {
        adj.get(edge[0]).add(edge[1]);
        inDegree[edge[1]]++;
    }
    
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < n; i++) {
        if (inDegree[i] == 0) {
            queue.add(i);
        }
    }
    
    int[] result = new int[n];
    int index = 0;
    
    while (!queue.isEmpty()) {
        int node = queue.poll();
        result[index++] = node;
        
        for (int neighbor : adj.get(node)) {
            inDegree[neighbor]--;
            if (inDegree[neighbor] == 0) {
                queue.add(neighbor);
            }
        }
    }
    
    // If we couldn't process all nodes, cycle exists
    return (index == n) ? result : new int[0];
}
```

**Speed**: O(V + E)

### 2. Union-Find (Disjoint Set)

**Simple Explanation**: Track which nodes are connected. Efficiently merge sets and find which set a node belongs to.

**Real-World Analogy**: Grouping friends into circles - quickly check if two people are in the same circle.

**Use Cases**: 
- Detect cycles in graph
- Kruskal's MST algorithm
- Connected components

**Operations**:
1. **Find(x)**: Which set does x belong to?
2. **Union(x, y)**: Merge sets containing x and y

**Optimizations**:
1. **Path Compression**: Make nodes point directly to root
2. **Union by Rank**: Always attach shorter tree under taller tree

**Step-by-Step Example**:

```
Initial: {0}, {1}, {2}, {3}, {4}

Union(0, 1): {0,1}, {2}, {3}, {4}
Union(2, 3): {0,1}, {2,3}, {4}
Union(1, 2): {0,1,2,3}, {4}

Find(0) = Find(1) = Find(2) = Find(3) = same set
Find(4) = different set
```

**Code**:

```java
class UnionFind {
    int[] parent;
    int[] rank;
    
    public UnionFind(int size) {
        parent = new int[size];
        rank = new int[size];
        for (int i = 0; i < size; i++) {
            parent[i] = i;  // Initially, each node is its own parent
            rank[i] = 0;
        }
    }
    
    // Find with path compression
    public int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // Path compression
        }
        return parent[x];
    }
    
    // Union by rank
    public void union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        
        if (rootX != rootY) {
            // Attach shorter tree under taller tree
            if (rank[rootX] > rank[rootY]) {
                parent[rootY] = rootX;
            } else if (rank[rootX] < rank[rootY]) {
                parent[rootX] = rootY;
            } else {
                parent[rootY] = rootX;
                rank[rootX]++;
            }
        }
    }
    
    // Check if two nodes are in same set
    public boolean connected(int x, int y) {
        return find(x) == find(y);
    }
}
```

**Speed**: 
- **Find**: O(α(n)) - nearly constant (inverse Ackermann)
- **Union**: O(α(n)) - nearly constant

### 3. Minimum Spanning Tree (MST)

**Simple Explanation**: Connect all nodes with minimum total edge weight.

**Real-World Analogy**: Connect all cities with roads using minimum total road length.

**Kruskal's Algorithm**:

**How it works**:
1. Sort all edges by weight
2. Start with empty MST
3. For each edge (smallest to largest):
   - If adding it doesn't create a cycle, add it
4. Stop when we have V-1 edges

**Uses Union-Find to detect cycles**

**Code**:

```java
public int kruskal(int n, int[][] edges) {
    // Sort edges by weight
    Arrays.sort(edges, (a, b) -> a[2] - b[2]);
    
    UnionFind uf = new UnionFind(n);
    int mstWeight = 0;
    int edgesAdded = 0;
    
    for (int[] edge : edges) {
        int u = edge[0];
        int v = edge[1];
        int w = edge[2];
        
        // If u and v are not connected, add edge
        if (uf.find(u) != uf.find(v)) {
            uf.union(u, v);
            mstWeight += w;
            edgesAdded++;
            
            if (edgesAdded == n - 1) break;
        }
    }
    
    return mstWeight;
}
```

**Speed**: O(E log E) for sorting

## Part 6: Graph Applications

### Application 1: Social Network Analysis

**Problem**: Find friends of friends, suggest connections.

**Solution**: BFS from a user to find people at distance 2.

```java
public List<Integer> suggestFriends(int user, List<List<Integer>> graph) {
    List<Integer> suggestions = new ArrayList<>();
    boolean[] visited = new boolean[graph.size()];
    Queue<Integer> queue = new LinkedList<>();
    
    visited[user] = true;
    queue.add(user);
    int level = 0;
    
    while (!queue.isEmpty() && level < 2) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            int curr = queue.poll();
            for (int friend : graph.get(curr)) {
                if (!visited[friend]) {
                    visited[friend] = true;
                    if (level == 1) {
                        suggestions.add(friend);
                    }
                    queue.add(friend);
                }
            }
        }
        level++;
    }
    
    return suggestions;
}
```

### Application 2: Cycle Detection

**Problem**: Check if graph has a cycle.

**Solution**: DFS with visited and recursion stack.

```java
public boolean hasCycle(List<List<Integer>> graph) {
    boolean[] visited = new boolean[graph.size()];
    boolean[] recStack = new boolean[graph.size()];
    
    for (int i = 0; i < graph.size(); i++) {
        if (dfsCycle(graph, i, visited, recStack)) {
            return true;
        }
    }
    return false;
}

private boolean dfsCycle(List<List<Integer>> graph, int node, 
                         boolean[] visited, boolean[] recStack) {
    if (recStack[node]) return true;  // Cycle found
    if (visited[node]) return false;
    
    visited[node] = true;
    recStack[node] = true;
    
    for (int neighbor : graph.get(node)) {
        if (dfsCycle(graph, neighbor, visited, recStack)) {
            return true;
        }
    }
    
    recStack[node] = false;
    return false;
}
```

### Application 3: Bipartite Graph Check

**Problem**: Can we color graph with 2 colors so no adjacent nodes have same color?

**Solution**: BFS/DFS with coloring.

```java
public boolean isBipartite(List<List<Integer>> graph) {
    int[] color = new int[graph.size()];
    Arrays.fill(color, -1);  // -1 = uncolored
    
    for (int i = 0; i < graph.size(); i++) {
        if (color[i] == -1) {
            if (!bfsBipartite(graph, i, color)) {
                return false;
            }
        }
    }
    return true;
}

private boolean bfsBipartite(List<List<Integer>> graph, int start, int[] color) {
    Queue<Integer> queue = new LinkedList<>();
    queue.add(start);
    color[start] = 0;
    
    while (!queue.isEmpty()) {
        int node = queue.poll();
        
        for (int neighbor : graph.get(node)) {
            if (color[neighbor] == -1) {
                color[neighbor] = 1 - color[node];
                queue.add(neighbor);
            } else if (color[neighbor] == color[node]) {
                return false;  // Same color as neighbor
            }
        }
    }
    return true;
}
```

### Mistake 1: Forgetting to Mark Visited

public void dfs(int node, List<List<Integer>> graph, boolean[] visited) {

}

## Summary

**Graph Representations**:
- **Adjacency Matrix**: O(V²) space, fast edge lookup
- **Adjacency List**: O(V+E) space, efficient for sparse graphs

**Traversal Algorithms**:
- **BFS**: Level-by-level, uses queue, shortest path (unweighted)
- **DFS**: Depth-first, uses stack/recursion, cycle detection

**Shortest Path**:
- **Dijkstra**: Positive weights only, O((V+E) log V)
- **Bellman-Ford**: Handles negative weights, O(VE)
- **Floyd-Warshall**: All-pairs, O(V³)

**Advanced Algorithms**:
- **Topological Sort**: Order tasks with dependencies
- **Union-Find**: Track connected components
- **MST (Kruskal's)**: Minimum cost to connect all nodes

**Key Principles**:
1. Choose right representation (matrix vs list)
2. Use BFS for unweighted shortest path
3. Use Dijkstra for weighted shortest path
4. Use DFS for cycle detection and topological sort
5. Always mark nodes as visited!
