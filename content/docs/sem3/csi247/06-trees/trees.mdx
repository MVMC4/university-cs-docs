# Trees Implementation

Trees model hierarchical relationships. Unlike linear structures (arrays, linked lists), trees branch — each node can have multiple children, enabling efficient search, sorted storage, and hierarchical organisation.

<PresetCard type="builds">
Tree traversals (in-order, pre-order, post-order) are all recursive. If recursion feels unclear, review **Chapter 3 (Recursion)** first. BFS (level-order traversal) uses a Queue — see **Chapter 4**.
</PresetCard>

## Part 1: Understanding Trees — The Basics

### What is a Tree?

A tree is a connected, acyclic graph with one designated root node. Every non-root node has exactly one parent.

### Tree Terminology

| Term | Definition |
|---|---|
| **Root** | The top-most node (no parent) |
| **Leaf** | A node with no children |
| **Height** | Longest path from root to any leaf |
| **Depth** | Distance from root to a given node |
| **Subtree** | A node and all its descendants |
| **Degree** | Number of children a node has |

## Part 2: Binary Trees

### What is a Binary Tree?

A binary tree is a tree where every node has **at most two children** — a left child and a right child.

```java
// Generic TreeNode — stores any Comparable type, not just int
public class TreeNode<T extends Comparable<T>> {
    T data;
    TreeNode<T> left;
    TreeNode<T> right;

    public TreeNode(T data) {
        this.data = data;
        this.left = null;
        this.right = null;
    }
}
```

<Callout type="info" title="Why Generic?">
Making `TreeNode` generic (`T extends Comparable<T>`) means your BST can store `Integer`, `String`, `Student`, or any type that defines a natural ordering. This is consistent with what you learned in Chapter 1 (Generics). A BST hardcoded to `int` is a toy implementation — real DSA uses generics.
</Callout>

### 1. Tree Traversals

The three depth-first traversals differ only in when the root is visited relative to its children.

<InteractiveStepper>
  <StepperStep title="In-Order: Left -> Root -> Right">
    Visits nodes in **ascending sorted order** for a valid BST. This is the defining property of in-order traversal.

    ```java
    public void inOrder(TreeNode<Integer> node) {
        if (node == null) return;
        inOrder(node.left);                          // 1. Left subtree
        System.out.print(node.data + " ");           // 2. Root
        inOrder(node.right);                         // 3. Right subtree
    }
    ```
    For a BST containing {4, 2, 6, 1, 3}: output is **1 2 3 4 6** (sorted ascending).
  </StepperStep>
  <StepperStep title="Pre-Order: Root -> Left -> Right">
    Visits the root **before** its children. Used to **clone** a tree or produce prefix expressions.

    ```java
    public void preOrder(TreeNode<Integer> node) {
        if (node == null) return;
        System.out.print(node.data + " ");           // 1. Root first
        preOrder(node.left);
        preOrder(node.right);
    }
    ```
    Same tree output: **4 2 1 3 6** — root first, then left subtree, then right.
  </StepperStep>
  <StepperStep title="Post-Order: Left -> Right -> Root">
    Visits the root **after** both children. Used to **delete** a tree (children before parent) or evaluate expression trees.

    ```java
    public void postOrder(TreeNode<Integer> node) {
        if (node == null) return;
        postOrder(node.left);
        postOrder(node.right);
        System.out.print(node.data + " ");           // 3. Root last
    }
    ```
    Same tree output: **1 3 2 6 4** — leaves first, root last.
  </StepperStep>
  <StepperStep title="Level-Order (BFS): Width-First using a Queue">
    Visits all nodes at depth d before any at depth d+1. Requires an explicit Queue.

    ```java
    public void levelOrder(TreeNode<Integer> root) {
        if (root == null) return;
        Queue<TreeNode<Integer>> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode<Integer> node = queue.poll();
            System.out.print(node.data + " ");
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }
    ```
    Same tree output: **4 2 6 1 3** — level by level.
  </StepperStep>
</InteractiveStepper>

### Traversal Comparison

| Traversal | Order | Key Use Case |
|---|---|---|
| In-Order | Left -> Root -> Right | Get sorted sequence from BST |
| Pre-Order | Root -> Left -> Right | Clone tree, serialise structure |
| Post-Order | Left -> Right -> Root | Delete tree, evaluate expression tree |
| Level-Order | By depth (BFS) | Find shortest path, print by level |

## Part 3: Binary Search Trees (BST)

### What is a Binary Search Tree?

A BST enforces a strict ordering property at every node:

> **Left subtree values &lt; Node value &lt; Right subtree values**

This property holds recursively for every node in the tree, enabling O(log n) average search, insert, and delete.

```java
public class BST<T extends Comparable<T>> {
    private TreeNode<T> root;

    public BST() { this.root = null; }
}
```

### BST Operations

#### Search in BST

```java
public boolean search(TreeNode<T> node, T key) {
    if (node == null) return false;
    int cmp = key.compareTo(node.data);
    if (cmp == 0) return true;
    if (cmp < 0) return search(node.left, key);
    return search(node.right, key);
}
```

#### Insert in BST — Step by Step

<InteractiveStepper>
  <StepperStep title="Start at the root, compare the new value">
    We want to insert **7** into a BST with root **10**.

    `7.compareTo(10)` -> 7 &lt; 10 -> go LEFT.
  </StepperStep>
  <StepperStep title="Recurse into the left subtree">
    At node **5**: `7.compareTo(5)` -> 7 &gt; 5 -> go RIGHT.
  </StepperStep>
  <StepperStep title="Find the null position and insert">
    At node **8**: `7.compareTo(8)` -> 7 &lt; 8 -> go LEFT -> null found.

    Create `new TreeNode(7)` and attach as the left child of 8.

    ```java
    public TreeNode<T> insert(TreeNode<T> node, T data) {
        if (node == null) return new TreeNode<>(data);  // Base case: insert here
        int cmp = data.compareTo(node.data);
        if (cmp < 0) node.left = insert(node.left, data);
        else if (cmp > 0) node.right = insert(node.right, data);
        // cmp == 0: duplicate — ignore (or handle per policy)
        return node;
    }
    ```
  </StepperStep>
</InteractiveStepper>

#### Delete in BST

Deletion has three cases based on the target node's children:

**Case 1: Leaf node** — simply remove it (return null).

**Case 2: One child** — replace the node with its child.

**Case 3: Two children** — replace the node's value with its **in-order successor** (smallest value in the right subtree), then delete the in-order successor from the right subtree.

```java
public TreeNode<T> delete(TreeNode<T> root, T key) {
    if (root == null) return null;
    int cmp = key.compareTo(root.data);
    if (cmp < 0) {
        root.left = delete(root.left, key);
    } else if (cmp > 0) {
        root.right = delete(root.right, key);
    } else {
        // Node found
        if (root.left == null) return root.right;   // Case 1 & 2
        if (root.right == null) return root.left;   // Case 2

        // Case 3: Two children — find in-order successor
        TreeNode<T> successor = findMin(root.right);
        root.data = successor.data;                 // Copy successor value
        root.right = delete(root.right, successor.data); // Delete successor
    }
    return root;
}

private TreeNode<T> findMin(TreeNode<T> node) {
    while (node.left != null) node = node.left;
    return node;
}
```

<Callout type="warn" title="The Two-Children Delete Case  --  Exam Focus">
The in-order successor is the **smallest value in the right subtree** — found by going right once, then left as far as possible. It is guaranteed to have at most one child (no left child), making it safe to delete.
</Callout>

### BST Performance

<CaseAnalysis title="BST: Balanced vs Degenerate">
  <Case
    condition="Balanced BST  --  O(log n) operations"
    explanation="When the tree is balanced, each comparison eliminates half the remaining nodes. Height ~ log2(n)."
  >
    | Operation | Complexity |
    |---|---|
    | Search | O(log n) |
    | Insert | O(log n) |
    | Delete | O(log n) |

    Achieved when insertions are in random order. The probability of a randomly inserted sequence producing a balanced tree is high — but not guaranteed.
  </Case>
  <Case
    condition="Degenerate BST  --  O(n) operations (the worst case)"
    explanation="Inserting elements in sorted or reverse-sorted order creates a BST that degenerates into a linked list. Height = n."
  >
    Insert `[1, 2, 3, 4, 5]` in order:
    ```
    1
     \
      2
       \
        3
         \
          4
    ```
    Every search traverses all n nodes. **Solution: AVL Trees or Red-Black Trees.**
  </Case>
</CaseAnalysis>

## Part 4: Advanced Tree Types

### 3. AVL Trees (Self-Balancing BST)

An AVL tree automatically rebalances after every insert or delete. At every node, the **balance factor** (height of left subtree - height of right subtree) must be in {-1, 0, 1}.

<Callout type="info" title="The Four Rotation Cases">

| Imbalance | Shape | Fix |
|---|---|---|
| Left-Left (balance=+2, child=+1) | Left-leaning chain | Single Right Rotation |
| Right-Right (balance=-2, child=-1) | Right-leaning chain | Single Left Rotation |
| Left-Right (balance=+2, child=-1) | Left-Right zig-zag | Left on child, then Right on node |
| Right-Left (balance=-2, child=+1) | Right-Left zig-zag | Right on child, then Left on node |

The zig-zag cases require **double rotations** because a single rotation would just transform one imbalance into another.
</Callout>

```java
private int height(TreeNode<Integer> node) {
    return (node == null) ? 0 : node.height;
}

private int getBalance(TreeNode<Integer> node) {
    return (node == null) ? 0 : height(node.left) - height(node.right);
}

private TreeNode<Integer> rotateRight(TreeNode<Integer> y) {
    TreeNode<Integer> x = y.left;
    TreeNode<Integer> T2 = x.right;
    x.right = y;
    y.left = T2;
    y.height = Math.max(height(y.left), height(y.right)) + 1;
    x.height = Math.max(height(x.left), height(x.right)) + 1;
    return x; // new root
}
```

### 4. Tries (Prefix Trees)

A Trie stores strings by sharing common prefixes. Each path from root to a terminal node spells out a stored word.

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26]; // One slot per letter a-z
    boolean isEndOfWord = false;
}

public void insert(TrieNode root, String word) {
    TrieNode curr = root;
    for (char c : word.toCharArray()) {
        int idx = c - 'a';
        if (curr.children[idx] == null) curr.children[idx] = new TrieNode();
        curr = curr.children[idx];
    }
    curr.isEndOfWord = true;
}

public boolean search(TrieNode root, String word) {
    TrieNode curr = root;
    for (char c : word.toCharArray()) {
        int idx = c - 'a';
        if (curr.children[idx] == null) return false;
        curr = curr.children[idx];
    }
    return curr.isEndOfWord;
}
```

**Complexity:** Search/Insert O(L) where L = length of string · Space O(ALPHABET_SIZE x L x N)

### 5. Finding Lowest Common Ancestor (LCA)

```java
public TreeNode<Integer> lca(TreeNode<Integer> root, int p, int q) {
    if (root == null) return null;
    // In a BST, use value comparisons to navigate
    if (p < root.data && q < root.data) return lca(root.left, p, q);
    if (p > root.data && q > root.data) return lca(root.right, p, q);
    return root; // Root is the LCA — p and q split here
}
```

### 6. Morris Traversal (O(1) Space In-Order)

Morris Traversal performs in-order traversal without a stack or recursion by temporarily threading right-child pointers back to inorder successors.

```java
public void morrisInOrder(TreeNode<Integer> root) {
    TreeNode<Integer> curr = root;
    while (curr != null) {
        if (curr.left == null) {
            System.out.print(curr.data + " ");
            curr = curr.right;
        } else {
            // Find in-order predecessor
            TreeNode<Integer> pred = curr.left;
            while (pred.right != null && pred.right != curr) pred = pred.right;

            if (pred.right == null) {
                pred.right = curr; // Thread the pointer
                curr = curr.left;
            } else {
                pred.right = null; // Restore the tree
                System.out.print(curr.data + " ");
                curr = curr.right;
            }
        }
    }
}
```

### Application 1: File System

```java
// Each directory node can have many children (N-ary tree)
class DirectoryNode {

    List<DirectoryNode> children = new ArrayList<>();
    boolean isFile;
}
```

### Application 2: Expression Trees

Post-order traversal evaluates an expression tree:

```java
public int evaluate(TreeNode<String> node) {
    if (node.left == null && node.right == null) return Integer.parseInt(node.data);
    int left  = evaluate(node.left);
    int right = evaluate(node.right);
    return switch (node.data) {
        case "+" -> left + right;
        case "-" -> left - right;
        case "*" -> left * right;
        case "/" -> left / right;
        default  -> throw new IllegalArgumentException("Unknown operator: " + node.data);
    };
}
```

### Application 3: Heap (Priority Queue)

A **max-heap** is a complete binary tree where every parent is larger than its children. Stored as an array: children of index `i` are at `2i+1` (left) and `2i+2` (right).

```java
public void buildMaxHeap(int[] arr) {
    // Floyd's bottom-up heapify — O(n)
    for (int i = arr.length / 2 - 1; i >= 0; i--) {
        heapify(arr, arr.length, i);
    }
}

private void heapify(int[] arr, int n, int i) {
    int largest = i;
    int left = 2 * i + 1, right = 2 * i + 2;
    if (left < n && arr[left] > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;
    if (largest != i) {
        int tmp = arr[i]; arr[i] = arr[largest]; arr[largest] = tmp;
        heapify(arr, n, largest);
    }
}
```

## Part 6: Common Mistakes

### Mistake 1: Forgetting the Base Case in Recursion

```java
// WRONG — infinite recursion, no null check
public void badTraversal(TreeNode<Integer> node) {
    badTraversal(node.left);
    System.out.print(node.data);
    badTraversal(node.right);
}

// RIGHT
public void goodTraversal(TreeNode<Integer> node) {
    if (node == null) return; // Base case!
    goodTraversal(node.left);
    System.out.print(node.data);
    goodTraversal(node.right);
}
```

### Mistake 2: Not Handling Degenerate Trees

Always consider what your BST looks like when elements are inserted in sorted order. If your algorithm assumes O(log n) height, it breaks on sorted input. Use AVL or pre-sort + build from middle.

### Mistake 3: Confusing In-Order Successor and Predecessor

- **In-order successor** = smallest value in the RIGHT subtree (go right once, then left as far as possible)
- **In-order predecessor** = largest value in the LEFT subtree (go left once, then right as far as possible)

Both are used in the two-children deletion case. The successor is more commonly used.
