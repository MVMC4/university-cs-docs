# Practice Questions: Algorithm Analysis (Big-O)

<ExamQuestion title="Question 1: Complex Loop Analysis [10 Marks]">
  <SubQuestion part="a" prompt={<>Analyze the nested loops where outer loop <code>i</code> multiplies by 2, inner loop <code>j</code> runs up to <code>i</code>, and <code>k</code> divides <code>N</code> by 2. Break down the iterations. [6]</>} solution={<>Outer loop runs log(N) times. Inner j-loop runs 1 + 2 + 4 ... + N times (geometric series sum = 2N). Inner k-loop runs log(N) times per outer iteration.</>} />
  <SubQuestion part="b" prompt={<>Formulate the mathematical summation and solve for the final Big-O complexity. [4]</>} solution={<>Sum of j-loop is O(N). Sum of k-loop is O(log^2 N). Total complexity is dominated by the j-loop: O(N).</>} />
</ExamQuestion>

<ExamQuestion title="Question 2: Amortized Analysis of a Custom Data Structure [12 Marks]">
  <SubQuestion part="a" prompt={<>A DynamicArray resizes (cost O(N)) when full. Every 5th insertion costs 10*N for defragmentation. Calculate total cost of M insertions using Aggregate Method. [6]</>} solution={<>Standard inserts: M. Resizes: N + N/2 + N/4 ... = 2N. Defrag: happens M/5 times, cost is sum of 10*i. Total is O(M^2) due to defrag.</>} />
  <SubQuestion part="b" prompt={<>What is the amortized time complexity per insertion? Show your proof. [4]</>} solution={<>Since total cost is O(M^2), amortized cost per insertion is O(M). It is not O(1) like a standard dynamic array.</>} />
  <SubQuestion part="c" prompt={<>Would the Accounting Method be easier here? Explain credit assignment. [2]</>} solution={<>Yes, assign O(i) credits to each insertion to pay for the future defragmentation cost that scales with current size.</>} />
</ExamQuestion>

<ExamQuestion title="Question 3: Recurrence Relations & Master Theorem [10 Marks]">
  <SubQuestion part="a" prompt={<>Solve $T(n) = 4T(n/2) + O(n^2 log n)$ [4]</>} solution={<>Case 2 of Master Theorem (with log factor). n^(log_2 4) = n^2. f(n) = n^2 log n. Result: O(n^2 log^2 n).</>} />
  <SubQuestion part="b" prompt={<>Solve $T(n) = 3T(n/4) + O(n)$ [3]</>} solution={<>Case 3. n^(log_4 3) ≈ n^0.79. f(n) = n is polynomially larger. Result: O(n).</>} />
  <SubQuestion part="c" prompt={<>Solve $T(n) = T(n-1) + O(n)$ [3]</>} solution={<>Master theorem doesn't apply. Expansion yields n + (n-1) + ... + 1 = n(n+1)/2. Result: O(n^2).</>} />
</ExamQuestion>

<ExamQuestion title="Question 4: Space Complexity Analysis [8 Marks]">
  <SubQuestion part="a" prompt={<>Draw the call stack at max depth for a recursive function that creates a new array of size + 1 at each step. [4]</>} solution={<>Stack depth is N. At depth i, an array of size i is created.</>} />
  <SubQuestion part="b" prompt={<>Calculate total heap memory. Is space O(N) or O(N^2)? Prove mathematically. [4]</>} solution={<>Sum of array sizes: 1 + 2 + ... + N = N(N+1)/2. Space complexity is O(N^2) because all arrays exist simultaneously in memory until garbage collected.</>} />
</ExamQuestion>
