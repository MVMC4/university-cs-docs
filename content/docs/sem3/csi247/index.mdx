# CSI247: Data Structures & Algorithms

This course introduces students to fundamental data structures, data abstraction, algorithm analysis, and design paradigms using Java.

## Course Details

| Attribute | Details |
| :--- | :--- |
| **Code** | CSI247 |
| **Title** | Data Structures & Algorithms |
| **Credits** | 3 |
| **Type** | Core |
| **Semester** | 3 |
| **Pre-requisites** | CSI142, ISS112 |
| **Co-requisites** | none |

## Course Synopsis
The curriculum is structured progressively to build from language fundamentals to advanced custom data structures:
1. **Java Foundations & OOP**: Classes, arrays, packages, OOP principles, and Generics.
2. **Algorithmic Thinking**: Recursion and Big-O notation.
3. **Algorithms**: Searching and sorting algorithms (array-based).
4. **Standard Libraries**: Using Java's pre-defined Collections Framework.
5. **Custom Implementations**: Building LinkedLists, Stacks, Queues, Hash Tables, Trees, and Graphs from scratch.

## Learning Outcomes
After completion of the course, students should be able to:
1. Apply advanced Java features including Generics and OOP principles.
2. Perform worst-case runtime analysis (Big-O) on algorithms.
3. Choose appropriate data structures for any given problem.
4. Implement user-defined data structures in Java from scratch.
5. Utilize Java's pre-defined Collections Framework effectively.
