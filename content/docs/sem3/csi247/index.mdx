# CSI247: Data Structures

> **Course objective:** Learn, implement, and apply common data structures in Java while understanding the costs and benefits of each choice.

## 2026/27 study sequence

The site now begins with the same foundation established by the current course outline:

1. **Java Fundamentals** — syntax, types, scope, strings, control flow, arrays, input, methods, and file I/O.
2. **Recursion** — base cases, recursive calls, and tracing the call stack.
3. **Algorithm Analysis** — Big-O notation and comparing algorithmic growth.
4. **Searching & Sorting** — algorithms applied to arrays.
5. **Java Collections** — using Java's predefined data structures.
6. **Data-structure implementations** — linked lists, stacks, and queues.

Later syllabus material will be added as the current semester notes become available.

## How to use each topic

Start with the visual canvas, complete the practice questions, and finish with the flashcards and quizzes. Use the [resources page](/docs/sem3/csi247/resources) to distinguish the current 2026 materials from archived lecture notes.

> There is no universally best data structure. The right choice depends on the operations a problem requires and the time and space costs you can accept.
