[5]</>} solution={<>Use nested loops to add <code>doubleValue()</code> of each element. Ensure row and column lengths match before processing.</>} />
  <SubQuestion part="b" prompt={<>Explain why we cannot instantiate a generic array in Java using <code>new T[rows][cols]</code> and describe the standard workaround. [3]</>} solution={<>Due to type erasure, Java doesn't know the runtime type of <code>T</code>. </ExamQuestion>
