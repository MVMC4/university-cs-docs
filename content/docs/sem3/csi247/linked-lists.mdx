# Linked Lists Implementation

Linked lists are one of the most fundamental data structures in computer science. Unlike arrays that store items in a continuous block, linked lists scatter nodes throughout memory and connect them with pointers (like a treasure hunt where each clue leads to the next).

> **Why Learn This?**
> Imagine you're building:
> - **Browser history**: Back/Forward buttons use doubly-linked lists
> - **Music playlist**: Songs linked together for next/previous
> - **Undo system**: Each action linked to previous state
> 
> Understanding linked lists helps you master pointers, memory management, and algorithm design!

---

## Part 1: Understanding Linked Lists - The Basics

### What is a Linked List?

**Simple Explanation**: A linked list is like a chain of paperclips. Each paperclip (node) holds data and connects to the next paperclip. To find the 5th paperclip, you must follow the chain from the beginning.

**Real-World Analogy**: A treasure hunt where:
- Each clue (node) contains data and directions to the next clue
- You can't jump directly to clue #5 - you must follow clues 1→2→3→4→5
- The last clue points to "END" (null)

### Array vs Linked List

<SafeImage 
  src="/images/csi247/array-vs-linkedlist.png" 
  alt="Array vs Linked List Memory Layout" 
  caption="Figure 1: Arrays store data contiguously (fast access), while linked lists scatter nodes in memory (flexible size)" 
  className="max-w-full h-auto"
/>

| Feature | Array | Linked List |
|---------|-------|-------------|
| **Memory** | Continuous block | Scattered nodes |
| **Access** | O(1) - Jump to index | O(n) - Must traverse |
| **Insert/Delete** | O(n) - Shift elements | O(1) - Change pointers |
| **Size** | Fixed (usually) | Dynamic (grows/shrinks) |
| **Memory overhead** | Low | Higher (stores pointers) |

## Part 2: Singly Linked List (SLL)

### What is a Singly Linked List?

**Simple Explanation**: Each node has two parts:
1. **Data**: The actual value
2. **Next**: Pointer to the next node

It's called "singly" because you can only move forward (one direction).

### Node Structure

```java
class Node {
    int data;      // The actual data
    Node next;     // Pointer to next node
    
    Node(int data) {
        this.data = data;
        this.next = null;
    }
}
```

**Visual Representation**:

```
Head → [Data|Next] → [Data|Next] → [Data|Next] → null
        Node 1         Node 2         Node 3
```

### 1. Creating a Linked List

**Step-by-Step Example**:

```java
// Create nodes
Node head = new Node(10);    // [10|null]
Node second = new Node(20);  // [20|null]
Node third = new Node(30);   // [30|null]

// Link them together
head.next = second;   // [10|→] → [20|null]
second.next = third;  // [10|→] → [20|→] → [30|null]

// Result: 10 → 20 → 30 → null
```

---

### 2. Traversing (Visiting All Nodes)

**Simple Explanation**: Start at head, visit each node, move to next until you reach null.

**Step-by-Step Example**:

```java
Node current = head;  // Start at beginning

while (current != null) {
    System.out.println(current.data);  // Process current node
    current = current.next;            // Move to next node
}

// Output: 10, 20, 30
```

**How it works**:
```
Step 1: current = head (points to 10)
        Print 10
        Move to next (20)

Step 2: current = node with 20
        Print 20
        Move to next (30)

Step 3: current = node with 30
        Print 30
        Move to next (null)

Step 4: current = null → Stop!
```

**Speed**: O(n) - Must visit every node

---

### 3. Inserting Nodes

#### Insert at Beginning (Head)

**Simple Explanation**: Create new node, point it to current head, update head.

**Step-by-Step Example**:

```java
// Insert 5 at beginning of: 10 → 20 → 30

Node newNode = new Node(5);
newNode.next = head;  // New node points to old head
head = newNode;       // Update head to new node

// Result: 5 → 10 → 20 → 30
```

  src="/images/csi247/insert-at-head.png" 
  alt="Insert at Head Visualization" 
  caption="Figure 3: Inserting at head - create node, point to old head, update head pointer" 
  className="max-w-full h-auto"
/>

**Speed**: O(1) - Instant! No traversal needed

---

#### Insert at End (Tail)

**Simple Explanation**: Traverse to end, create new node, link last node to new node.

**Step-by-Step Example**:

```java
// Insert 40 at end of: 10 → 20 → 30

Node newNode = new Node(40);

// Find the last node
Node current = head;
while (current.next != null) {
    current = current.next;  // Move to last node
}

// Link last node to new node
current.next = newNode;

// Result: 10 → 20 → 30 → 40
```

**Speed**: O(n) - Must traverse to find end

---

#### Insert at Position

**Simple Explanation**: Traverse to position-1, insert new node between current and next.

**Step-by-Step Example**:

```java
// Insert 25 at position 2 (0-indexed) in: 10 → 20 → 30
// Result should be: 10 → 25 → 20 → 30

Node newNode = new Node(25);

// Find node at position 1 (before insertion point)
Node current = head;
for (int i = 0; i < 1; i++) {
    current = current.next;  // Now at node 20
}

// Insert new node
newNode.next = current.next;  // New node points to 20
current.next = newNode;       // Node 10 now points to 25

// Result: 10 → 25 → 20 → 30
```

**Speed**: O(n) - Must traverse to position

### 4. Deleting Nodes

#### Delete from Beginning

**Simple Explanation**: Move head to next node, old head gets garbage collected.

**Step-by-Step Example**:

```java
// Delete head from: 10 → 20 → 30

head = head.next;  // Head now points to 20

// Result: 20 → 30 (node 10 is garbage collected)
```

**Speed**: O(1) - Instant!

---

#### Delete from End

**Simple Explanation**: Traverse to second-to-last node, set its next to null.

**Step-by-Step Example**:

```java
// Delete last node from: 10 → 20 → 30

// Find second-to-last node
Node current = head;
while (current.next.next != null) {
    current = current.next;  // Now at node 20
}

// Remove last node
current.next = null;

// Result: 10 → 20 (node 30 is garbage collected)
```

**Speed**: O(n) - Must traverse to end

---

#### Delete by Value

**Simple Explanation**: Find the node, update previous node's next pointer.

**Step-by-Step Example**:

```java
// Delete node with value 20 from: 10 → 20 → 30

Node current = head;

// Find the node before the one to delete
while (current.next != null && current.next.data != 20) {
    current = current.next;  // Now at node 10
}

// Skip over the node to delete
if (current.next != null) {
    current.next = current.next.next;
}

// Result: 10 → 30 (node 20 is garbage collected)
```

**Speed**: O(n) - Must search for value

### 5. Reversing a Linked List

**Simple Explanation**: Flip all pointers so the list goes backwards.

**How It Works**:
1. Keep track of: previous node, current node, next node
2. Reverse current node's pointer
3. Move all pointers one step forward
4. Repeat until end

**Step-by-Step Example**:

```java
public Node reverseList(Node head) {
    Node prev = null;
    Node curr = head;
    
    while (curr != null) {
        // Step 1: Store next node (before we lose it)
        Node nextTemp = curr.next;
        
        // Step 2: Reverse the pointer
        curr.next = prev;
        
        // Step 3: Move pointers forward
        prev = curr;
        curr = nextTemp;
    }
    
    // prev is now the new head
    return prev;
}

// Example: Reverse 10 → 20 → 30

// Initial:  prev = null, curr = 10
// 
// Iteration 1:
//   nextTemp = 20
//   10.next = null
//   prev = 10, curr = 20
//   Result: null ← 10   20 → 30
//
// Iteration 2:
//   nextTemp = 30
//   20.next = 10
//   prev = 20, curr = 30
//   Result: null ← 10 ← 20   30
//
// Iteration 3:
//   nextTemp = null
//   30.next = 20
//   prev = 30, curr = null
//   Result: null ← 10 ← 20 ← 30
//
// Final: 30 → 20 → 10 → null
```

  className="max-w-full h-auto"

**Speed**: O(n) - Visit each node once  
**Space**: O(1) - Only using three pointers

## Part 3: Doubly Linked List (DLL)

### What is a Doubly Linked List?

**Simple Explanation**: Each node has THREE parts:
1. **Data**: The actual value
2. **Next**: Pointer to next node
3. **Prev**: Pointer to previous node

You can move both forward AND backward!

### Node Structure

```java
class Node {
    int data;
    Node next;  // Forward pointer
    Node prev;  // Backward pointer
    
    Node(int data) {
        this.data = data;
        this.next = null;
        this.prev = null;
    }
}
```

**Visual Representation**:

```
null ← [Prev|Data|Next] ↔ [Prev|Data|Next] ↔ [Prev|Data|Next] → null
           Node 1              Node 2              Node 3
```

### 6. Doubly Linked List Operations

#### Insert at Beginning

**Simple Explanation**: Create new node, link it to old head, update old head's prev pointer.

**Step-by-Step Example**:

```java
// Insert 5 at beginning of: 10 ↔ 20 ↔ 30

Node newNode = new Node(5);
newNode.next = head;      // New node points forward to 10
head.prev = newNode;      // Old head points back to new node
head = newNode;           // Update head

// Result: 5 ↔ 10 ↔ 20 ↔ 30
```

**Speed**: O(1) - Instant!

---

#### Delete Node

**Simple Explanation**: Update neighbors' pointers to skip over the node.

**Step-by-Step Example**:

```java
// Delete node 20 from: 10 ↔ 20 ↔ 30

Node toDelete = findNode(20);  // Find node with value 20

// Update neighbors
toDelete.prev.next = toDelete.next;  // 10.next = 30
toDelete.next.prev = toDelete.prev;  // 30.prev = 10

// Result: 10 ↔ 30 (node 20 is garbage collected)
```

**Speed**: O(1) if you have the node, O(n) to find it

**Advantage over SLL**: No need to track previous node!

---

#### Traverse Backward

**Simple Explanation**: Start at tail, follow prev pointers.

**Step-by-Step Example**:

```java
// Find tail first
Node tail = head;
while (tail.next != null) {
    tail = tail.next;
}

// Traverse backward
Node current = tail;
while (current != null) {
    System.out.println(current.data);
    current = current.prev;
}

// Output: 30, 20, 10
```

**Speed**: O(n)

## Part 4: Advanced Operations

### 7. Finding the Middle Node

**Simple Explanation**: Use two pointers - one moves 1 step, one moves 2 steps. When fast reaches end, slow is at middle.

**Real-World Analogy**: Two runners on a track. When the fast runner finishes, the slow runner is halfway.

**Step-by-Step Example**:

```java
public Node findMiddle(Node head) {
    Node slow = head;
    Node fast = head;
    
    while (fast != null && fast.next != null) {
        slow = slow.next;        // Move 1 step
        fast = fast.next.next;   // Move 2 steps
    }
    
    return slow;  // slow is at middle
}

// Example: 10 → 20 → 30 → 40 → 50
// 
// Step 1: slow=10, fast=10
// Step 2: slow=20, fast=30
// Step 3: slow=30, fast=50
// Step 4: fast.next=null, stop
// Result: slow points to 30 (middle)
```

**Speed**: O(n) - One pass through list  
**Space**: O(1) - Only two pointers

### 8. Detecting Cycles (Floyd's Algorithm)

**Simple Explanation**: Use two pointers moving at different speeds. If there's a cycle, they will eventually meet.

**Real-World Analogy**: Running on a circular track. If you run faster than someone else, you'll eventually lap them.

**How It Works**:
1. **Slow pointer**: Moves 1 step at a time
2. **Fast pointer**: Moves 2 steps at a time
3. If fast reaches null → No cycle
4. If fast meets slow → Cycle exists!

**Step-by-Step Example**:

```java
public boolean hasCycle(Node head) {
    Node slow = head;
    Node fast = head;
    
    while (fast != null && fast.next != null) {
        slow = slow.next;        // 1 step
        fast = fast.next.next;   // 2 steps
        
        if (slow == fast) {
            return true;  // Cycle detected!
        }
    }
    
    return false;  // No cycle
}

// Example with cycle: 10 → 20 → 30 → 40 → 20 (cycle back)
// 
// Step 1: slow=10, fast=10
// Step 2: slow=20, fast=30
// Step 3: slow=30, fast=20 (fast wrapped around)
// Step 4: slow=40, fast=40 → MEET! Cycle detected!
```

### 9. Finding Cycle Start

**Simple Explanation**: Once cycle is detected, reset one pointer to head. Move both 1 step at a time. Where they meet is the cycle start.

**Step-by-Step Example**:

```java
public Node findCycleStart(Node head) {
    Node slow = head;
    Node fast = head;
    
    // Phase 1: Detect cycle
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        
        if (slow == fast) {
            // Cycle detected, find start
            break;
        }
    }
    
    if (fast == null || fast.next == null) {
        return null;  // No cycle
    }
    
    // Phase 2: Find cycle start
    slow = head;  // Reset slow to head
    
    while (slow != fast) {
        slow = slow.next;
        fast = fast.next;
    }
    
    return slow;  // This is the cycle start
}

// Example: 10 → 20 → 30 → 40 → 50 → 30 (cycle back to 30)
// 
// Phase 1: Detect cycle
//   slow and fast meet at node 40
// 
// Phase 2: Find start
//   slow = head (10), fast = 40
//   Move both 1 step:
//   slow=20, fast=50
//   slow=30, fast=30 → MEET!
//   
// Result: Cycle starts at node 30
```

**Why This Works**: Mathematical proof shows that distance from head to cycle start equals distance from meeting point to cycle start.

## Part 5: Real-World Applications

### Application 1: Browser History

**How it works**: Doubly linked list where:
- Each node = a webpage
- next = Forward button
- prev = Back button
- current = Current page

```java
class BrowserHistory {
    Node current;
    
    void visit(String url) {
        Node newNode = new Node(url);
        newNode.prev = current;
        current.next = newNode;
        current = newNode;
    }
    
    String back() {
        if (current.prev != null) {
            current = current.prev;
        }
        return current.data;
    }
    
    String forward() {
        if (current.next != null) {
            current = current.next;
        }
        return current.data;
    }
}
```

---

### Application 2: Music Playlist

**How it works**: Circular linked list where last song points back to first.

```java
// Circular playlist: Song1 → Song2 → Song3 → Song1 (loop)

class Playlist {
    Node current;
    
    void playNext() {
        current = current.next;  // Wraps around automatically
    }
    
    void playPrevious() {
        // Need DLL for this, or track previous

    }
}
```

### Application 3: LRU Cache

**How it works**: Doubly linked list + HashMap
- Most recently used = head
- Least recently used = tail
- When cache full, remove tail

### When to Use Linked Lists?

**Use Linked Lists When**:
- ✅ You need frequent insertions/deletions
- ✅ You don't know the size in advance
- ✅ Memory is fragmented
- ✅ Implementing stacks, queues, graphs

**Don't Use Linked Lists When**:
- ❌ You need random access
- ❌ Memory is tight (overhead of pointers)
- ❌ You traverse sequentially most of the time (arrays have better cache locality)

## Part 7: Common Mistakes

### Mistake 1: Forgetting to Update Pointers

```java
// WRONG: Loses reference to rest of list
Node newNode = new Node(5);
head = newNode;  // Lost reference to old list!

// CORRECT
Node newNode = new Node(5);
newNode.next = head;
head = newNode;
```

### Mistake 2: Not Handling Edge Cases

```java
// WRONG: Crashes on empty list
public void deleteFirst() {
    head = head.next;  // NullPointerException if head is null!
}

// CORRECT
public void deleteFirst() {
    if (head != null) {
        head = head.next;
    }
}
```

### Mistake 3: Creating Cycles Accidentally

```java
// WRONG: Creates infinite loop
Node a = new Node(1);
Node b = new Node(2);
a.next = b;
b.next = a;  // Cycle! Will loop forever when traversing
```

## Summary

**Singly Linked List**:
- Simple, one direction
- Less memory
- Good for stacks, queues

**Doubly Linked List**:
- Two directions (prev + next)
- More memory
- Good for browser history, undo systems

**Key Operations**:
- Insert/Delete at head: O(1)
- Insert/Delete at tail: O(n) for SLL, O(1) for DLL
- Search/Access: O(n)
- Reverse: O(n) time, O(1) space

**Advanced Algorithms**:
- Find middle: Fast/slow pointers
- Detect cycle: Floyd's algorithm
- Find cycle start: Reset one pointer

**Remember**: 
- Linked lists trade memory access speed for flexible insertion
- Arrays are faster for traversal (cache locality)
- Choose based on your needs!
