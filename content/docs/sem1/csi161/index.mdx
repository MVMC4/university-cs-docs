# CSI161: Introduction to Computing

This course provides a holistic overview of modern computing systems. It explores the information processing cycle, the intricate relationship between hardware and software, and the foundational architectures that enable complex computations. The objective is to equip students with a comprehensive understanding of how data is represented, processed, stored, and transmitted across global networks.

## Scope and Coverage

The curriculum examines computing from the physical hardware level up to application software and network infrastructure. Core topics include:

1. **The Information Processing Cycle**: Input, processing, output, and storage mechanisms, alongside the societal impact of computer literacy.
2. **Hardware and Software Ecosystems**: Physical components (CPU, memory hierarchies, I/O devices) and the distinction between system software and application software.
3. **Computer Organization and Architecture**: The Von Neumann architecture, system buses, and data representation (binary, octal, hexadecimal systems).
4. **Networks and Telecommunications**: Network topologies, communication protocols, and the foundational infrastructure of the Internet.
5. **Emerging Technologies**: Cloud computing paradigms, artificial intelligence, and future trends in computational systems.

## Suggested Progression

1. Begin with **Computer Architecture and Hardware** to understand the physical machinery and data representation.
2. Proceed to **Software Ecosystems** to examine how the hardware is controlled and utilized by operating systems and applications.
3. Study **Networks and Telecommunications** to understand the protocols governing global data transmission.
4. Conclude with **Emerging Technologies** to contextualize the future trajectory of the computing industry.
