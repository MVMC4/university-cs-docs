# CSI141: Programming Principles

This course provides a comprehensive introduction to the fundamental concepts and principles of programming using a high-level, object-oriented language (Java). The primary objective is to develop essential problem-solving skills and software development practices, transitioning students from computational thinking to the implementation of functional, robust software solutions.

## Scope and Coverage

The curriculum covers the building blocks of modern programming languages and the methodologies required to structure code for real-world problem-solving. Core topics include:

1. **The Programming Process**: Compilation, execution, data representation, and the anatomy of a computer system.
2. **Fundamental Data Types and I/O**: Primitive variables, strings, type casting, and standard keyboard/console input/output operations.
3. **Control Structures**: Boolean logic, conditional statements (`if/else`, `switch`), and iterative loops (`while`, `for`).
4. **Data Collections**: Storing, manipulating, and traversing data using arrays and `ArrayLists`.
5. **Modularity and Object-Orientation**: Designing reusable methods, understanding variable scope, and introducing user-defined classes and objects.
6. **File I/O and Exception Handling**: Reading from and writing to external files, and managing runtime errors gracefully.

## Suggested Progression

1. Begin with **Fundamental Data Types and I/O** to understand how data is stored, manipulated, and presented.
2. Master **Control Structures** to dictate the logical flow and decision-making capabilities of a program.
3. Study **Arrays and Methods** to learn how to write modular, reusable code and handle bulk data efficiently.
4. Conclude with **Classes and File I/O**, which are essential for building persistent, real-world applications.
