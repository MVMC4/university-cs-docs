# Graph Algorithm Patterns

This page is a decision guide and complexity reference for graph algorithms. Use it when you know you have a graph problem but need to choose the right algorithm.

<PresetCard type="builds">
Graph traversal (BFS and DFS) uses Queue and Stack respectively — see **Chapter 4**. Dijkstra's algorithm uses a PriorityQueue — see the Collections chapter. Union-Find underpins Kruskal's MST — all covered here.
</PresetCard>

## 1. Algorithm Selection Framework

<CaseAnalysis title="Which graph algorithm do I use?">
  <Case
    condition="Unweighted graph  --  find shortest path (fewest edges)"
    explanation="BFS explores level by level, guaranteeing the minimum edge count to reach any node. Use it whenever all edge weights are equal (or there are no weights)."
  >
    **Algorithm: BFS** — O(V + E)

    ```java
    int[] dist = new int[V];
    Arrays.fill(dist, -1);
    Queue<Integer> q = new ArrayDeque<>();
    dist[src] = 0;
    q.offer(src);
    while (!q.isEmpty()) {
        int u = q.poll();
        for (int v : adj.get(u)) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.offer(v);
            }
        }
    }
    ```

    Use when: social network friend distance, maze shortest path, word ladder.
  </Case>
  <Case
    condition="Weighted graph with non-negative weights  --  find shortest path"
    explanation="Dijkstra's algorithm uses a greedy approach: always expand the unvisited node with the smallest known distance. Requires non-negative weights to guarantee correctness."
  >
    **Algorithm: Dijkstra's** — O((V + E) log V) with a binary heap PriorityQueue

    ```java
    int[] dist = new int[V];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[1]));
    pq.offer(new int[]{src, 0});
    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int u = curr[0], d = curr[1];
        if (d > dist[u]) continue; // Stale entry — skip
        for (int[] edge : adj.get(u)) { // edge = {neighbour, weight}
            int v = edge[0], w = edge[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{v, dist[v]});
            }
        }
    }
    ```

    Use when: GPS navigation, network routing, game pathfinding.
  </Case>
  <Case
    condition="Weighted graph WITH negative edges  --  single source shortest path"
    explanation="Dijkstra's fails with negative weights because a later-discovered path can be shorter than one already finalised. Bellman-Ford relaxes all edges V-1 times, allowing negative weights."
  >
    **Algorithm: Bellman-Ford** — O(V x E)

    ```java
    int[] dist = new int[V];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;
    // Relax all edges V-1 times
    for (int i = 0; i < V - 1; i++) {
        for (int[] edge : edges) { // edge = {u, v, weight}
            int u = edge[0], v = edge[1], w = edge[2];
            if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
            }
        }
    }
    // V-th relaxation: if distances still change, negative cycle exists
    for (int[] edge : edges) {
        if (dist[edge[0]] + edge[2] < dist[edge[1]])
            throw new RuntimeException("Negative cycle detected");
    }
    ```

    Use when: currency arbitrage detection, networks with cost rebates.
  </Case>
  <Case
    condition="All-pairs shortest paths"
    explanation="Floyd-Warshall computes shortest paths between every pair of vertices in one pass. Trades O(V^2) space for simplicity."
  >
    **Algorithm: Floyd-Warshall** — O(V^3) time, O(V^2) space

    ```java
    int[][] dist = new int[V][V]; // Initialise with edge weights, 0 on diagonal, INF elsewhere
    for (int k = 0; k < V; k++) {       // Intermediate vertex
        for (int i = 0; i < V; i++) {   // Source
            for (int j = 0; j < V; j++) { // Destination
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
    ```

    Use when: small dense graphs, computing transitive closure, network diameter.
  </Case>
</CaseAnalysis>

## 3. Topological Sort

Topological sort orders vertices of a **Directed Acyclic Graph (DAG)** such that for every directed edge u -> v, u appears before v in the ordering.

<Callout type="warn" title="Only possible on DAGs">
Topological sort is undefined for graphs with cycles. If a cycle exists, it is impossible to linearise the vertices. Always check for cycles first (or detect them during the sort).
</Callout>

### Kahn's Algorithm (BFS-based)

```java
public List<Integer> topologicalSort(int V, List<List<Integer>> adj) {
    int[] inDegree = new int[V];
    for (int u = 0; u < V; u++)
        for (int v : adj.get(u)) inDegree[v]++;

    Queue<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < V; i++)
        if (inDegree[i] == 0) queue.offer(i); // Start with nodes that have no prerequisites

    List<Integer> order = new ArrayList<>();
    while (!queue.isEmpty()) {
        int u = queue.poll();
        order.add(u);
        for (int v : adj.get(u)) {
            inDegree[v]--;
            if (inDegree[v] == 0) queue.offer(v);
        }
    }
    // If order.size() != V, graph has a cycle
    return order.size() == V ? order : Collections.emptyList();
}
```

### DFS-based Topological Sort

```java
public void dfsTopoSort(int u, boolean[] visited, Deque<Integer> stack, List<List<Integer>> adj) {
    visited[u] = true;
    for (int v : adj.get(u))
        if (!visited[v]) dfsTopoSort(v, visited, stack, adj);
    stack.push(u); // Push AFTER all descendants are processed (post-order)
}
// Call for all unvisited nodes, then pop stack for topological order
```

## 4. Union-Find (Disjoint Set Union)

Union-Find efficiently answers: "Are nodes u and v in the same connected component?"

```java
public class UnionFind {
    private int[] parent, rank;

    public UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i; // Each node is its own root
    }

    // Path compression: flatten the tree as we search
    public int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    // Union by rank: attach smaller tree under larger tree
    public boolean union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return false; // Already in same component — adding edge creates cycle
        if (rank[rx] < rank[ry]) parent[rx] = ry;
        else if (rank[rx] > rank[ry]) parent[ry] = rx;
        else { parent[ry] = rx; rank[rx]++; }
        return true;
    }

    public boolean connected(int x, int y) { return find(x) == find(y); }
}
```

**Complexity:** With path compression + union by rank: O(alpha(n)) per operation, where alpha is the inverse Ackermann function — effectively O(1) for all practical n.

## 5. Minimum Spanning Tree

An MST connects all vertices with the minimum total edge weight. Two classic algorithms:

  columns={[
    { header: "Property", key: "prop" },

  ]}
  rows={[
    { prop: "Approach", kruskal: "Edge-centric: sort all edges, add if no cycle", prim: "Vertex-centric: grow MST one vertex at a time" },
    { prop: "Data structure", kruskal: "Sort + Union-Find", prim: "Priority Queue" },
    { prop: "Complexity", kruskal: "O(E log E)", prim: "O((V + E) log V)" },
    { prop: "Best for", kruskal: "Sparse graphs (few edges)", prim: "Dense graphs (many edges)" },
    { prop: "Implementation", kruskal: "Sort edges, union-find for cycle detection", prim: "Similar to Dijkstra's but track edge weights" },
  ]}
/>

```java
// Kruskal's MST
public int kruskalMST(int V, int[][] edges) { // edges: {u, v, weight}
    Arrays.sort(edges, Comparator.comparingInt(e -> e[2])); // Sort by weight
    UnionFind uf = new UnionFind(V);
    int totalWeight = 0, edgesUsed = 0;
    for (int[] edge : edges) {
        if (uf.union(edge[0], edge[1])) { // Add edge if it doesn't create a cycle
            totalWeight += edge[2];
            if (++edgesUsed == V - 1) break; // MST has exactly V-1 edges
        }
    }
    return totalWeight;
}
```

## 6. Complexity Quick Reference

| Algorithm | Time | Space | Requires |
|---|---|---|---|
| BFS | O(V + E) | O(V) | — |
| DFS | O(V + E) | O(h) | — |
| Dijkstra's | O((V+E) log V) | O(V) | Non-negative weights |
| Bellman-Ford | O(VE) | O(V) | Any weights |
| Floyd-Warshall | O(V^3) | O(V^2) | Any weights |
| Topological Sort | O(V + E) | O(V) | DAG only |
| Union-Find (path compress + rank) | O(alpha(n)) per op | O(V) | — |
| Kruskal's MST | O(E log E) | O(V) | Undirected |
| Prim's MST | O((V+E) log V) | O(V) | Undirected |
