# Stacks and Queues Implementation

Stacks and queues are like specialized containers with strict rules about how you add and remove items. Think of them as different types of lines or piles with specific behaviors.

> **Why Learn This?**
> Imagine you're building:
> - **Undo system**: Uses a stack (last action undone first)
> - **Print queue**: Uses a queue (first document printed first)
> - **Task scheduler**: Uses a priority queue (urgent tasks first)
> 
> These data structures are the backbone of many algorithms and systems!

---

## Part 1: Understanding the Basics

### What are Stacks and Queues?

**Simple Explanation**: 
- **Stack**: Like a stack of plates - you add to the top and remove from the top (LIFO - Last In, First Out)
- **Queue**: Like a line at a store - you join at the back and leave from the front (FIFO - First In, First Out)

**Real-World Examples**:

**Stack (LIFO)**:
- Browser back button (last page visited is first to go back to)
- Undo in text editor (last change is first to undo)
- Stack of books (take from top)
- Pancake stack (eat from top)

**Queue (FIFO)**:
- Printer queue (first document sent prints first)
- Ticket counter line (first person in line gets served first)
- Call center hold (first caller gets answered first)
- Conveyor belt (first item on is first item off)

## Part 2: Stacks - Last In, First Out (LIFO)

### 1. What is a Stack?

**Simple Explanation**: A stack is like a vertical pile. You can only add or remove from the top. You can't reach into the middle.

**Key Operations**:
1. **Push**: Add item to top
2. **Pop**: Remove item from top
3. **Peek**: Look at top item without removing
4. **isEmpty**: Check if stack is empty

### 2. Stack Operations - Step by Step

#### Push Operation (Adding to Stack)

**Simple Explanation**: Put a new item on top of the pile.

**Step-by-Step Example**:

```
Initial: Empty stack

Step 1: Push 10
[10]

Step 2: Push 20
[20]
[10]

Step 3: Push 30
[30]
[20]
[10]

Top is 30, bottom is 10
```

**Code**:
```java
Stack<Integer> stack = new Stack<>();

stack.push(10);  // Stack: [10]
stack.push(20);  // Stack: [10, 20]
stack.push(30);  // Stack: [10, 20, 30]
```

**Speed**: O(1) - Instant! Just add to top

---

#### Pop Operation (Removing from Stack)

**Simple Explanation**: Take the top item off the pile.

**Step-by-Step Example**:

```
Stack: [10, 20, 30]  (30 is on top)

Step 1: Pop
Returns: 30
Stack: [10, 20]

Step 2: Pop
Returns: 20
Stack: [10]

Step 3: Pop
Returns: 10
Stack: [] (empty)
```

**Code**:
```java
Stack<Integer> stack = new Stack<>();
stack.push(10);
stack.push(20);
stack.push(30);

int top = stack.pop();  // Returns 30, Stack: [10, 20]
top = stack.pop();      // Returns 20, Stack: [10]
```

**Speed**: O(1) - Instant! Just remove from top

---

#### Peek Operation (Looking at Top)

**Simple Explanation**: Look at the top item without removing it.

**Step-by-Step Example**:

```
Stack: [10, 20, 30]

Peek: Returns 30
Stack stays: [10, 20, 30] (unchanged)
```

**Code**:
```java
Stack<Integer> stack = new Stack<>();
stack.push(10);
stack.push(20);

int top = stack.peek();  // Returns 20
// Stack is still [10, 20] - nothing removed!
```

**Speed**: O(1) - Instant!

### 3. Implementing a Stack

#### Using Array

**Simple Explanation**: Use an array with a pointer to track the top.

**Step-by-Step Implementation**:

```java
class MyStack {
    private int[] arr;
    private int top;  // Points to top element
    private int capacity;
    
    public MyStack(int size) {
        capacity = size;
        arr = new int[capacity];
        top = -1;  // -1 means empty
    }
    
    // Push: Add to top
    public void push(int x) {
        if (top == capacity - 1) {
            System.out.println("Stack overflow!");
            return;
        }
        top++;           // Move top pointer up
        arr[top] = x;    // Add element
    }
    
    // Pop: Remove from top
    public int pop() {
        if (top == -1) {
            System.out.println("Stack underflow!");
            return -1;
        }
        int value = arr[top];  // Get top value
        top--;                 // Move top pointer down
        return value;
    }
    
    // Peek: Look at top
    public int peek() {
        if (top == -1) {
            return -1;
        }
        return arr[top];
    }
    
    // Check if empty
    public boolean isEmpty() {
        return top == -1;
    }
}
```

**Visual Walkthrough**:

```
Create stack of size 3: top = -1
[]

Push 10: top becomes 0, arr[0] = 10
[10]  ← top at index 0

Push 20: top becomes 1, arr[1] = 20
[10, 20]  ← top at index 1

Push 30: top becomes 2, arr[2] = 30
[10, 20, 30]  ← top at index 2

Pop: Return arr[2] = 30, top becomes 1
[10, 20]  ← top at index 1
```

---

#### Using Linked List

**Simple Explanation**: Use a linked list where you only add/remove from the head.

**Code**:
```java
class Node {
    int data;
    Node next;
    Node(int data) { this.data = data; }
}

class StackUsingLinkedList {
    private Node top;
    
    // Push: Add to front
    public void push(int x) {
        Node newNode = new Node(x);
        newNode.next = top;  // New node points to old top
        top = newNode;       // Update top to new node
    }
    
    // Pop: Remove from front
    public int pop() {
        if (top == null) {
            System.out.println("Stack underflow!");
            return -1;
        }
        int value = top.data;
        top = top.next;  // Move top to next node
        return value;
    }
}
```

**Speed Comparison**:

| Operation | Array Stack | Linked List Stack |
|-----------|-------------|-------------------|
| **Push** | O(1) | O(1) |
| **Pop** | O(1) | O(1) |
| **Peek** | O(1) | O(1) |
| **Memory** | Fixed size | Dynamic size |

### 4. Stack Applications

#### Application 1: Undo System

**Simple Explanation**: Every action is pushed to stack. Undo pops the last action.

**How it works**:

```
User types "Hello"
Stack: ["type H", "type e", "type l", "type l", "type o"]

User presses Undo
Pop: "type o" → Remove 'o'
Stack: ["type H", "type e", "type l", "type l"]
Text: "Hell"

User presses Undo again
Pop: "type l" → Remove 'l'
Stack: ["type H", "type e", "type l"]
Text: "Hel"
```

**Code**:
```java
Stack<String> undoStack = new Stack<>();

// User types
undoStack.push("Added: Hello");
undoStack.push("Added: World");

// User undoes
String lastAction = undoStack.pop();  // "Added: World"
// Undo the action...
```

#### Application 2: Balanced Parentheses

**Simple Explanation**: Use stack to check if parentheses are balanced.

**How it works**:

```
Expression: "({[]})"

Step 1: See '(' → Push to stack
Stack: ['(']

Step 2: See '{' → Push
Stack: ['(', '{']

Step 3: See '[' → Push
Stack: ['(', '{', '[']

Step 4: See ']' → Pop and check match
Pop '[' → Matches ']' ✓
Stack: ['(', '{']

Step 5: See '}' → Pop and check
Pop '{' → Matches '}' ✓
Stack: ['(']

Step 6: See ')' → Pop and check
Pop '(' → Matches ')' ✓
Stack: [] (empty)

Result: Balanced!
```

**Code**:
```java
public boolean isBalanced(String expr) {
    Stack<Character> stack = new Stack<>();
    
    for (char c : expr.toCharArray()) {
        if (c == '(' || c == '{' || c == '[') {
            stack.push(c);  // Push opening bracket
        } else {
            if (stack.isEmpty()) return false;
            
            char top = stack.pop();
            
            // Check if brackets match
            if ((c == ')' && top != '(') ||
                (c == '}' && top != '{') ||
                (c == ']' && top != '[')) {
                return false;
            }
        }
    }
    
    return stack.isEmpty();  // True if all matched
}
```

#### Application 3: Infix to Postfix Conversion

**Simple Explanation**: Convert `3 + 4 * 5` to `3 4 5 * +` using stack.

**Why?** Postfix is easier for computers to evaluate.

**How it works**:

```
Infix: 3 + 4 * 5
Postfix: 3 4 5 * +

Algorithm:
1. Numbers → Output directly
2. Operators → Push to stack
3. Higher precedence → Push
4. Lower precedence → Pop from stack first

Step-by-step:
Read 3 → Output: 3
Read + → Push to stack: [+]
Read 4 → Output: 3 4
Read * → * has higher precedence than +, push: [+, *]
Read 5 → Output: 3 4 5
End → Pop all: Output: 3 4 5 * +
```

**Simple Explanation**: Join the line at the back.

**Step-by-Step Example**:

```
Initial: Empty queue

Step 1: Enqueue 10
[10]
Front    Back

Step 2: Enqueue 20
[10, 20]

**Simple Explanation**: Leave from the front of the line.

**Step-by-Step Example**:

```
Queue: [10, 20, 30]
Front  Back

Step 1: Dequeue
Returns: 10 (front)
Queue: [20, 30]
Front  Back

Step 2: Dequeue
Returns: 20
Queue: [30]
Front/Back

Step 3: Dequeue
Returns: 30
Queue: [] (empty)
```

queue.add(30);

int front = queue.remove();  // Returns 10, Queue: [20, 30]
front = queue.remove();      // Returns 20, Queue: [30]
```

**Speed**: O(1) - Instant!

### 7. Implementing a Queue

#### Using Array (Simple Queue)

**Problem**: When we dequeue, we leave empty space at the front that we can't reuse!

**Step-by-Step**:

```java
class SimpleQueue {
    private int[] arr;
    private int front;
    private int rear;
    private int capacity;
    
    public SimpleQueue(int size) {
        capacity = size;
        arr = new int[capacity];
        front = 0;
        rear = -1;
    }
    
    public void enqueue(int x) {
        if (rear == capacity - 1) {
            System.out.println("Queue is full!");
            return;
        }
        rear++;
        arr[rear] = x;
    }
    
    public int dequeue() {
        if (front > rear) {
            System.out.println("Queue is empty!");
            return -1;
        }
        int value = arr[front];
        front++;  // Move front forward
        return value;
    }
}
```

**Visual Walkthrough**:

```
Queue of size 3: front=0, rear=-1
[_, _, _]

Enqueue 10: rear=0, arr[0]=10
[10, _, _]
 ↑
front/rear

Enqueue 20: rear=1, arr[1]=20
[10, 20, _]
 ↑   ↑
front rear

Dequeue: Return arr[0]=10, front=1
[10, 20, _]
    ↑  ↑
  front rear

Enqueue 30: rear=2, arr[2]=30
[10, 20, 30]
    ↑     ↑
  front  rear

Dequeue: Return arr[1]=20, front=2
[10, 20, 30]
        ↑
    front/rear

Problem: Queue looks full but only has 1 element!
We wasted positions 0 and 1.
```

#### Using Circular Queue (Better!)

**Simple Explanation**: When we reach the end, wrap around to the beginning using modulo.

**How it works**:

```
Queue of size 3 using modulo arithmetic

Enqueue 10: rear = (0+1)%3 = 1
[10, _, _]

Enqueue 20: rear = (1+1)%3 = 2
[10, 20, _]

Enqueue 30: rear = (2+1)%3 = 0 (wraps around!)
[10, 20, 30]
 ↑        ↑
rear    front

Dequeue: front = (0+1)%3 = 1
[10, 20, 30]
    ↑   ↑
  front rear

Enqueue 40: rear = (0+1)%3 = 1
[40, 20, 30]
    ↑   ↑
  rear front

Now we reused position 0!
```

**Code**:

```java
class CircularQueue {
    private int[] arr;
    private int front;
    private int rear;
    private int capacity;
    private int size;  // Track current size
    
    public CircularQueue(int size) {
        capacity = size;
        arr = new int[capacity];
        front = 0;
        rear = -1;
        this.size = 0;
    }
    
    public void enqueue(int x) {
        if (size == capacity) {
            System.out.println("Queue is full!");
            return;
        }
        
        // Move rear forward with wrapping
        rear = (rear + 1) % capacity;
        arr[rear] = x;
        size++;
    }
    
    public int dequeue() {
        if (size == 0) {
            System.out.println("Queue is empty!");
            return -1;
        }
        
        int value = arr[front];
        // Move front forward with wrapping
        front = (front + 1) % capacity;
        size--;
        return value;
    }
    
    public int peek() {
        if (size == 0) return -1;
        return arr[front];
    }
    
    public boolean isEmpty() {
        return size == 0;
    }
    
    public boolean isFull() {
        return size == capacity;
    }
}
```

#### Using Linked List

**Simple Explanation**: Use a linked list with pointers to both front and back.

**Code**:

```java
class Node {
    int data;
    Node next;
    Node(int data) { this.data = data; }
}

class QueueUsingLinkedList {
    private Node front;
    private Node rear;
    
    public QueueUsingLinkedList() {
        front = null;
        rear = null;
    }
    
    // Enqueue: Add to back
    public void enqueue(int x) {
        Node newNode = new Node(x);
        
        if (rear == null) {
            // Queue is empty
            front = newNode;
            rear = newNode;
            return;
        }
        
        // Add to back and update rear
        rear.next = newNode;
        rear = newNode;
    }
    
    // Dequeue: Remove from front
    public int dequeue() {
        if (front == null) {
            System.out.println("Queue is empty!");
            return -1;
        }
        
        int value = front.data;
        front = front.next;
        
        // If queue becomes empty, update rear too
        if (front == null) {
            rear = null;
        }
        
        return value;
    }
}
```

**Visual Walkthrough**:

```
Enqueue 10:
front → [10] ← rear

Enqueue 20:
front → [10] → [20] ← rear

Enqueue 30:
front → [10] → [20] → [30] ← rear

Dequeue:
Remove front (10)
front → [20] → [30] ← rear

Dequeue:
Remove front (20)
front → [30] ← rear

Dequeue:
Remove front (30)
front = null, rear = null (empty)
```

### 8. Queue Applications

#### Application 1: Breadth-First Search (BFS)

**Simple Explanation**: Explore neighbors level by level using a queue.

**How it works**:

```
Graph:     1
         / \
        2   3
       / \
      4   5

BFS starting from 1:

Step 1: Enqueue 1
Queue: [1]
Visited: {1}

Step 2: Dequeue 1, enqueue neighbors 2, 3
Queue: [2, 3]
Visited: {1, 2, 3}
Output: 1

Step 3: Dequeue 2, enqueue neighbors 4, 5
Queue: [3, 4, 5]
Visited: {1, 2, 3, 4, 5}
Output: 1, 2

Step 4: Dequeue 3 (no new neighbors)
Queue: [4, 5]
Output: 1, 2, 3

Step 5: Dequeue 4 (no new neighbors)
Queue: [5]
Output: 1, 2, 3, 4

Step 6: Dequeue 5 (no new neighbors)
Queue: []
Output: 1, 2, 3, 4, 5

Result: Level-by-level traversal!
```

## Part 4: Advanced Topics

### 9. Deque (Double-Ended Queue)

**Simple Explanation**: A deque allows adding and removing from BOTH ends.

**Real-World Analogy**: A line where you can join or leave from either the front or back.

**Operations**:
- **addFirst**: Add to front
- **addLast**: Add to back
- **removeFirst**: Remove from front
- **removeLast**: Remove from back

**Code**:

```java
Deque<Integer> deque = new ArrayDeque<>();

deq.addFirst(10);   // [10]
deq.addLast(20);    // [10, 20]
deq.addFirst(5);    // [5, 10, 20]
deq.addLast(30);    // [5, 10, 20, 30]

deq.removeFirst();  // Returns 5, [10, 20, 30]
deq.removeLast();   // Returns 30, [10, 20]
```

**When to use**:
- Sliding window problems
- Palindrome checking
- Undo/redo systems

### 10. Monotonic Stack/Deque

**Simple Explanation**: A stack/deque that maintains elements in sorted order (increasing or decreasing).

**Real-World Example**: Finding the maximum in a sliding window.

**Problem**: Find maximum in every window of size 3 in `[1, 3, -1, -3, 5, 3, 6, 7]`

**How Monotonic Deque works**:

```
Array: [1, 3, -1, -3, 5, 3, 6, 7]
Window size: 3

Use deque to store INDICES, maintaining decreasing values

i=0, val=1:
Deque: [0] (value 1)

i=1, val=3:
Remove 0 (value 1 < 3, can never be max)
Deque: [1] (value 3)

i=2, val=-1:
Add 2 (value -1 < 3, keep both)
Deque: [1, 2] (values 3, -1)
Window [0-2]: Max is arr[1] = 3

i=3, val=-3:
Add 3 (value -3 < -1, keep all)
Deque: [1, 2, 3] (values 3, -1, -3)
Remove 1 (index 1 out of window)
Deque: [2, 3] (values -1, -3)
Window [1-3]: Max is arr[2] = -1

i=4, val=5:
Remove 2, 3 (values -1, -3 < 5)
Deque: [4] (value 5)
Window [2-4]: Max is arr[4] = 5

Continue...

Result: [3, 3, 5, 5, 6, 7]
```

**Code**:

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> deque = new ArrayDeque<>();  // Store indices
    int[] result = new int[nums.length - k + 1];
    
    for (int i = 0; i < nums.length; i++) {
        // Remove indices out of window
        while (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.removeFirst();
        }
        
        // Remove smaller elements from back
        while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) {
            deque.removeLast();
        }
        
        // Add current index
        deque.addLast(i);
        
        // Record max for this window
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    
    return result;
}
```

**Speed**: O(n) - Each element added and removed at most once!

### 11. Priority Queue (Min-Heap/Max-Heap)

**Simple Explanation**: A queue where elements are removed by priority, not by arrival order.

**Real-World Examples**:
- Emergency room (most critical patients first)
- Task scheduler (urgent tasks first)
- Dijkstra's algorithm (shortest distance first)

**Types**:
- **Min-Heap**: Smallest element has highest priority
- **Max-Heap**: Largest element has highest priority

**How it works**:

```
Max-Heap Example:

Insert 10:
    [10]

Insert 20:
    [20]
    / 
  [10]

Insert 15:
      [20]
     /  \
  [10] [15]

Extract Max:
Returns 20
      [15]
     /
  [10]

Insert 25:
      [25]
     /  \
  [10] [15]

Extract Max:
Returns 25
      [15]
     /
  [10]
```

**Code**:

```java
// Min-Heap (smallest first)
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
minHeap.add(10);
minHeap.add(5);
minHeap.add(20);

minHeap.poll();  // Returns 5 (smallest)
minHeap.poll();  // Returns 10
minHeap.poll();  // Returns 20

// Max-Heap (largest first)
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
maxHeap.add(10);
maxHeap.add(5);
maxHeap.add(20);

maxHeap.poll();  // Returns 20 (largest)
maxHeap.poll();  // Returns 10
maxHeap.poll();  // Returns 5
```

**Speed**:
- Insert: O(log n)
- Extract min/max: O(log n)
- Peek: O(1)

### 13. Common Mistakes

#### Mistake 1: Stack Underflow

```java
// WRONG: Popping from empty stack
Stack<Integer> stack = new Stack<>();
stack.pop();  // EmptyStackException!

// CORRECT: Check if empty first
if (!stack.isEmpty()) {
    stack.pop();
}
```

#### Mistake 2: Queue Overflow

```java
// WRONG: Adding to full queue without checking
CircularQueue queue = new CircularQueue(3);
queue.enqueue(1);
queue.enqueue(2);
queue.enqueue(3);
queue.enqueue(4);  // Error!

// CORRECT: Check if full
if (!queue.isFull()) {
    queue.enqueue(4);
}
```

#### Mistake 3: Using Stack for FIFO

```java
// WRONG: Stack is LIFO, not FIFO
Stack<Integer> stack = new Stack<>();
stack.push(1);
stack.push(2);
stack.pop();  // Returns 2, not 1!

// CORRECT: Use Queue for FIFO
Queue<Integer> queue = new LinkedList<>();
queue.add(1);
queue.add(2);
queue.remove();  // Returns 1 (first in, first out)
```

## Summary

**Stacks (LIFO)**:
- Push/Pop from top only
- Use for: Undo, DFS, parentheses matching, recursion
- O(1) operations

**Queues (FIFO)**:
- Enqueue at back, Dequeue from front
- Use for: BFS, scheduling, buffering
- O(1) operations

**Circular Queue**:
- Reuses empty space with modulo arithmetic
- More efficient than simple queue

**Deque**:
- Add/remove from both ends
- Use for: Sliding window, palindrome

**Priority Queue**:
- Remove by priority, not order
- Use for: Dijkstra, task scheduling
- O(log n) insert/extract

**Key Principles**:
1. Choose stack for LIFO, queue for FIFO
2. Use circular queue to save memory
3. Monotonic deque for sliding window problems
4. Priority queue for priority-based access
