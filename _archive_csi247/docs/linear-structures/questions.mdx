# Practice Questions: Linear Data Structures

<ExamQuestion title="Question 1: Complex Linked List Manipulation [12 Marks]">
  <SubQuestion part="a" prompt={<>Write <code>reversePositiveBlocks(Node head, int k)</code>. Reverse blocks of size k ONLY if the sum of amounts in the block is &gt; 0.0. [8]</>} solution={<>Use a helper to calculate block sum. If &gt; 0, apply standard k-group reverse logic. If &le; 0, advance pointers without reversing.</>} />
  <SubQuestion part="b" prompt={<>Time and space complexity? [2]</>} solution={<>Time: O(N) because we traverse each node a constant number of times. Space: O(1) auxiliary if done iteratively.</>} />
  <SubQuestion part="c" prompt={<>How does pointer manipulation change for a Doubly Linked List? [2]</>} solution={<>You must update both <code>next</code> and <code>prev</code> pointers during the swap, and ensure the head/tail boundary conditions link correctly.</>} />
</ExamQuestion>

<ExamQuestion title="Question 2: Advanced Stack Operations (Infix to Postfix) [15 Marks]">
  <SubQuestion part="a" prompt={<>Trace Shunting Yard for <code>A + B * C ! ^ D - E</code> where ! is highest precedence and ^ is right-associative. [8]</>} solution={<>! binds tightest to C. ^ binds next (right-assoc means D^(!C) evaluates right-to-left). * binds next. + and - bind last. Postfix: A B C ! D ^ * + E -</>} />
  <SubQuestion part="b" prompt={<>Write <code>evaluatePostfix(String expr)</code> handling division-by-zero. [7]</>} solution={<>Use a stack of integers. Push operands. On operator, pop two, apply math (check denominator != 0 for /), push result.</>} />
</ExamQuestion>

<ExamQuestion title="Question 3: Circular Queue Implementation [15 Marks]">
  <SubQuestion part="a" prompt={<>Write <code>enqueue</code> and <code>dequeue</code> using modulo operator <code>%</code>. [6]</>} solution={<>rear = (rear + 1) % capacity; front = (front + 1) % capacity;</>} />
  <SubQuestion part="b" prompt={<>Explain why size N array holds N-1 elements if front==rear means empty. How to resolve? [5]</>} solution={<>If full, rear wraps to front, mimicking empty state. Resolve by keeping a <code>size</code> counter or a boolean <code>isFull</code> flag.</>} />
  <SubQuestion part="c" prompt={<>Write <code>jumpQueue</code> to insert directly behind <code>front</code>. [4]</>} solution={<>Calculate index (front - 1 + capacity) % capacity. Shift elements backwards or use a secondary buffer if array is completely full.</>} />
</ExamQuestion>

<ExamQuestion title="Question 4: Mathematical Linked Lists [8 Marks]">
  <SubQuestion part="a" prompt={<>Add two numbers stored in reverse order linked lists. Handle carry. [5]</>} solution={<>Iterate both lists simultaneously. Sum = l1.val + l2.val + carry. New node = sum % 10. carry = sum / 10.</>} />
  <SubQuestion part="b" prompt={<>How to modify if stored in forward order without reversing lists or using O(N) stack? [3]</>} solution={<>Pad the shorter list with leading zeros. Use recursion to reach the end, compute sum and carry on the way back up the call stack (O(H) stack space, which is O(N) technically, but no explicit data structure).</>} />
</ExamQuestion>
