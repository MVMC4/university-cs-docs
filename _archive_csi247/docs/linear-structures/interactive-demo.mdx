# Pointer Mechanics — Interactive Walkthrough

The most common source of bugs in linked list code is incorrect pointer sequencing. These walkthroughs show the exact order of operations required for safe pointer manipulation.

---

## Linked List: Insert in the Middle

We want to insert a new node with value **42** between nodes **A** and **C** in the list `A → C → D`.

<InteractiveStepper>
  <StepperStep title="Step 1: Traverse to the predecessor node (A)">
    Start at `head`. Walk the list until you reach the node **before** the insertion point.

    ```java
    Node curr = head;
    while (curr != null && curr.data != targetPrev) {
        curr = curr.next;
    }
    // curr now points to node A
    ```

    **State:** `curr → A`, `A.next → C`
  </StepperStep>
  <StepperStep title="Step 2: Create the new node">
    ```java
    Node newNode = new Node(42);
    ```

    **State:** `newNode → [42 | null]`, `curr → A`, `A.next → C`
  </StepperStep>
  <StepperStep title="Step 3: Point new node to the successor FIRST">
    This step MUST happen before step 4. If you disconnect A->C before saving the reference to C, you lose the rest of the list.

    ```java
    newNode.next = curr.next; // newNode → C
    ```

    **State:** `newNode.next → C`, `A.next → C` (still unchanged)
  </StepperStep>
  <StepperStep title="Step 4: Point predecessor to new node">
    Now it is safe to update A's pointer, because newNode already holds the reference to C.

    ```java
    curr.next = newNode; // A → newNode
    ```

    **Final state:** `A → [42] → C → D` ✓
  </StepperStep>
</InteractiveStepper>

<PresetCard type="trap">
**The #1 pointer bug:** Updating `curr.next = newNode` BEFORE saving `newNode.next = curr.next`. Once `curr.next` is overwritten, the reference to C is gone and the rest of the list is unreachable (memory leak).
</PresetCard>

## Linked List: Delete a Middle Node

Delete node **C** from the list `A → C → D`.

<InteractiveStepper>
  <StepperStep title="Step 1: Traverse to the predecessor of the node to delete">
    ```java
    Node curr = head;
    while (curr.next != null && curr.next.data != targetVal) {
        curr = curr.next;
    }
    // curr → A, curr.next → C (the node to delete)
    ```
  </StepperStep>
  <StepperStep title="Step 2: Save reference to the node being deleted">
    ```java
    Node toDelete = curr.next; // toDelete → C
    ```
    Optional in Java (GC handles memory), but good practice and required in C/C++.
  </StepperStep>
  <StepperStep title="Step 3: Bypass the deleted node">
    ```java
    curr.next = curr.next.next; // A.next → D (skip C)
    ```

    **Final state:** `A → D` ✓  Node C is now unreferenced and will be garbage-collected.
  </StepperStep>
</InteractiveStepper>

## Stack: Balanced Parentheses Algorithm

Given a string of brackets, determine if they are balanced.

<InteractiveStepper>
  <StepperStep title="Setup: Use a stack for opening brackets">
    ```java
    Deque<Character> stack = new ArrayDeque<>();
    String input = "{[()]}";
    ```
    Rule: Push every opening bracket. On closing bracket, pop and check it matches.
  </StepperStep>
  <StepperStep title="Process: '{' -> push, '[' -> push, '(' -> push">
    Input: `{ [ ( ) ] }`

    After `{`: stack = `[{]`

    After `[`: stack = `[{, []`

    After `(`: stack = `[{, [, (]`
  </StepperStep>
  <StepperStep title="Process: ')' -> pop '('  --  match! ']' -> pop '['  --  match!">
    After `)`: pop `(`, compare -> `(` matches `)` ✓ stack = `[{, []`

    After `]`: pop `[`, compare -> `[` matches `]` ✓ stack = `[{]`
  </StepperStep>
  <StepperStep title="Process: '}' -> pop '{'  --  match! Stack is empty  --  BALANCED">
    After `}`: pop `{`, compare -> `{` matches `}` ✓ stack = `[]`

    Stack is empty -> **return true** (balanced).

    ```java
    public boolean isBalanced(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                stack.push(c);
            } else {
                if (stack.isEmpty()) return false; // Closing bracket with nothing to match
                char top = stack.pop();
                if ((c == ')' && top != '(') ||
                    (c == ']' && top != '[') ||
                    (c == '}' && top != '{')) return false;
            }
        }
        return stack.isEmpty(); // True only if all brackets matched
    }
    ```
  </StepperStep>
</InteractiveStepper>
