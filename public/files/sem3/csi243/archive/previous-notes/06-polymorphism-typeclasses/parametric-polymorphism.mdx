## 6.1 Parametric Polymorphism

**Parametric polymorphism** allows a function to operate uniformly on values of *any* type. We denote unknown types with lowercase type variables (e.g., `a`, `b`). The function's behaviour cannot depend on the specific type; it can only manipulate the structure of the data.

<HighlightCard
  variant="neutral"
  title="Definition 6.1.1: Parametric vs. Monomorphic"
  description="Parametric functions do the exact same structural thing regardless of type, while monomorphic functions are restricted to specific types."
>

- **Monomorphic:** `swapIntegers :: (Int, Int) -> (Int, Int)`. Works only for `Int`. The compiler generates machine code specifically for integer registers.
- **Parametrically Polymorphic:** `swapElements :: (a, b) -> (b, a)`. Works for *any* combination of types. Because it is parametric, the function *cannot* inspect, create, or depend on the values of `a` or `b`. It can only deconstruct the tuple and reorder the components.

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Example: The 5-Part Framework (`lastElement`)</StepByStepTitle>

  <Step number={1}>
    <StepTitle>1. Signature</StepTitle>
    `lastElement :: [a] -> a`
  </Step>

  <Step number={2}>
    <StepTitle>2. Mathematical Specification</StepTitle>
    ```text
    lastElement(xs) = {
      error           if xs = []
      x               if xs = [x]
      lastElement(ys) if xs = y:ys
    }
    ```
  </Step>

  <Step number={3}>
    <StepTitle>3. Dry Run</StepTitle>
    `lastElement [1, 2]`
    `=> lastElement (1 : [2])`
    `=> lastElement [2]`
    `=> 2`
  </Step>

  <Step number={4}>
    <StepTitle>4. Implementation</StepTitle>
    ```haskell
    lastElement :: [a] -> a
    lastElement [x]    = x
    lastElement (_:xs) = lastElement xs
    lastElement []     = error "Empty list"
    ```
  </Step>

  <Step number={5}>
    <StepTitle>5. Polymorphism Check</StepTitle>
    The type variable `a` means this works for any list. It only inspects the list structure (`[]` and `:`), never the elements themselves.
  </Step>
</StepByStep>

<HighlightCard
  variant="neutral"
  title="Theorem 6.1.1: The Complexity of Naive Reversal"
  description="The recursive step `revList xs ++ [x]` uses the `++` operator, which must traverse its entire left operand. This results in $O(n^2)$ time complexity for a list of length $n$."
>

```haskell
revList :: [a] -> [a]
revList []     = []
revList (x:xs) = revList xs ++ [x]
```
*An $O(n)$ version requires an accumulator pattern (e.g., `reverse'`).*

</HighlightCard>

<Card>

### Definition 6.1.2 (Free Theorems / Parametricity)

Philip Wadler's "Theorems for Free" states that parametric polymorphism restricts what a function can do. For `id :: a -> a`, the function knows *nothing* about `a`. It cannot inspect it, create it, or destroy it. The *only* terminating implementation is `id x = x`.

</Card>
