## 7.3 Mathematical Reasoning

Because Haskell functions are pure and referentially transparent, we can prove their correctness algebraically, just like mathematical theorems.

<HighlightCard
  variant="neutral"
  title="Definition 7.3.1: Equational Reasoning"
  description="The process of proving function equivalence by substituting equals for equals, relying on Referential Transparency."
>

If a function is pure, any expression can be replaced by its evaluated value without changing the program's behavior. This allows us to chain equalities (`=`) with justifications for each step.

</HighlightCard>

<HighlightCard
  variant="neutral"
  title="Definition 7.3.2: Structural Induction Framework"
  description="The formal proof framework for recursive data types (like lists or trees)."
>

1. **Basis Step:** Prove the property holds for the base case (e.g., `[]` or `Leaf`).
2. **Inductive Hypothesis (IH):** Assume the property holds for a smaller structure (e.g., `xs`).
3. **Inductive Step:** Prove the property holds for the larger structure (e.g., `x:xs`) using the IH.

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Mandatory Proof 1: `length (xs ++ ys) = length xs + length ys`</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Basis Step (xs = [])</StepTitle>
    `length ([] ++ ys)`
    `= length ys`  -- Definition of `++`: `[] ++ ys = ys`
    `= 0 + length ys` -- Arithmetic
    `= length [] + length ys` -- Definition of `length`: `length [] = 0`
  </Step>

  <Step number={2}>
    <StepTitle>Inductive Hypothesis</StepTitle>
    Assume `length (xs ++ ys) = length xs + length ys` holds for some list `xs`.
  </Step>

  <Step number={3}>
    <StepTitle>Inductive Step (x:xs)</StepTitle>
    `length ((x:xs) ++ ys)`
    `= length (x : (xs ++ ys))` -- Definition of `++`: `(x:xs) ++ ys = x : (xs ++ ys)`
    `= 1 + length (xs ++ ys)` -- Definition of `length`: `length (z:zs) = 1 + length zs`
    `= 1 + (length xs + length ys)` -- Apply Inductive Hypothesis
    `= (1 + length xs) + length ys` -- Associativity of `+`
    `= length (x:xs) + length ys` -- Definition of `length`
  </Step>
</StepByStep>

<StepByStep>
  <StepByStepTitle>Mandatory Proof 2: `map (f . g) = map f . map g`</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Basis Step (xs = [])</StepTitle>
    `map (f . g) []`
    `= []` -- Definition of `map`: `map h [] = []`
    `= map f []` -- Definition of `map`
    `= map f (map g [])` -- Definition of `map`
    `= (map f . map g) []` -- Definition of `.`: `(h1 . h2) x = h1 (h2 x)`
  </Step>

  <Step number={2}>
    <StepTitle>Inductive Hypothesis</StepTitle>
    Assume `map (f . g) xs = map f (map g xs)` holds for some list `xs`.
  </Step>

  <Step number={3}>
    <StepTitle>Inductive Step (x:xs)</StepTitle>
    `map (f . g) (x:xs)`
    `= (f . g) x : map (f . g) xs` -- Definition of `map`
    `= f (g x) : map (f . g) xs` -- Definition of `.`
    `= f (g x) : map f (map g xs)` -- Apply Inductive Hypothesis
    `= map f (g x : map g xs)` -- Definition of `map` (reverse direction)
    `= map f (map g (x:xs))` -- Definition of `map` (reverse direction)
    `= (map f . map g) (x:xs)` -- Definition of `.`
  </Step>
</StepByStep>
