## 7.1 Currying and Closures

In Haskell, *every* function takes exactly **one** argument. The appearance of multi-argument functions is an illusion created by currying.

<HighlightCard
  variant="neutral"
  title="Definition 7.1.1: Currying"
  description="The process of transforming a function that takes multiple arguments into a sequence of functions that each take a single argument."
>

The type signature `Int -> Int -> Int` is right-associative. It is actually parsed as:
`Int -> (Int -> Int)`

This means a function takes an `Int` and returns a *new function* of type `Int -> Int`.

</HighlightCard>

<Card>

### Definition 7.1.2 (Partial Application & Lexical Closures)

When you apply a curried function to fewer arguments than it expects, you get a **partially applied function**. This new function is a **lexical closure**: it captures the arguments provided so far in its environment, waiting for the remaining arguments.

```haskell
add :: Int -> Int -> Int
add x y = x + y

addFive :: Int -> Int
addFive = add 5  -- Partial application creates a closure capturing x=5
```

</Card>

<HighlightCard
  variant="neutral"
  title="Definition 7.1.3: Function Composition `(.)`"
  description="Combines two functions into a new function, feeding the output of the right function into the left function."
>

```haskell
(.) :: (b -> c) -> (a -> b) -> (a -> c)
(f . g) x = f (g x)
```

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Example: Deriving Point-Free Style via Eta-Reduction</StepByStepTitle>

  <Step number={1}>
    <StepTitle>The Goal</StepTitle>
    Transform `\x -> filter (> 5) (map (* 2) x)` into point-free style.
  </Step>

  <Step number={2}>
    <StepTitle>Recognize Inner Application</StepTitle>
    `map (* 2) x` is the function `map (* 2)` applied to `x`.
    Rewrite: `\x -> filter (> 5) ((map (* 2)) x)`
  </Step>

  <Step number={3}>
    <StepTitle>Apply Composition Definition</StepTitle>
    Recall `(f . g) x = f (g x)`. Let `f = filter (> 5)` and `g = map (* 2)`.
    Rewrite: `\x -> (filter (> 5) . map (* 2)) x`
  </Step>

  <Step number={4}>
    <StepTitle>Eta-Reduce</StepTitle>
    Since `\x -> h x` is equivalent to `h` (for all `x`), we drop the `\x ->` and the trailing `x`.
    Result: `filter (> 5) . map (* 2)`
  </Step>
</StepByStep>
