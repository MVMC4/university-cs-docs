# Support

University CS Docs is a community-maintained educational project, not an official University of Botswana support channel.

## Choose the right channel

- **Documentation error or broken page:** open a Content issue.
- **Application defect:** open a Bug report.
- **Feature or course proposal:** open a Feature request or GitHub Discussion.
- **Setup question:** check the README and CONTRIBUTING guide first, then use a Discussion.
- **Security vulnerability:** report it privately according to SECURITY.md.
- **Conduct concern:** use the private reporting options in CODE_OF_CONDUCT.md.

When asking for help, include the route or file, expected and actual behavior, browser or Node.js version where relevant, and a minimal reproduction.

Maintainers and contributors respond on a best-effort basis. The project cannot provide private tutoring, grade disputes, official course interpretation, or guaranteed response times.
