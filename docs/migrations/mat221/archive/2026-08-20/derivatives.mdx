# Derivatives

The derivative of a function measures the sensitivity to change of the function value (output value) with respect to a change in its argument (input value).

## Core Formulas
- **Power Rule**: $\frac\{d\}\{dx\}[x^n] = nx^\{n-1\}$
- **Product Rule**: $\frac\{d\}\{dx\}[f(x)g(x)] = f'(x)g(x) + f(x)g'(x)$
- **Quotient Rule**: $\frac\{d\}\{dx\}\left[\frac\{f(x)\}\{g(x)\}\right] = \frac\{f'(x)g(x) - f(x)g'(x)\}\{[g(x)]^2\}$
- **Chain Rule**: $\frac\{d\}\{dx\}[f(g(x))] = f'(g(x)) \cdot g'(x)$

## Example Application
Find the derivative of $f(x) = (3x^2 + 1)^4$.
Using the **Chain Rule**:
1. Outer function derivative: $4(3x^2 + 1)^3$
2. Inner function derivative: $6x$
3. Result: $f'(x) = 4(3x^2 + 1)^3 \cdot 6x = 24x(3x^2 + 1)^3$
