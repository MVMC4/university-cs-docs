## Capture note

The already-running development server did not change the document theme after the visible toggle was activated. The same interaction worked on a fresh production server. Only production-server captures are retained as canonical baselines.

The retained images use fixed viewports. Full-page stitched trials were discarded after visual inspection found duplicated sticky elements and repeated long-page sections in the capture output.
